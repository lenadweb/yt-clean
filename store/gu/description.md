YouTube Clean, Shorts, ભલામણો, ટિપ્પણીઓ અને જાહેરાતો છુપાવે છે — પાના પર ફક્ત એ જ વીડિયો બાકી રહે છે જે જોવા તમે આવ્યા હતા.

YouTube એવી રીતે બનેલું છે કે તમે સ્ક્રોલ કરતા જ રહો: ક્યારેય ન ખૂટતું Shorts શેલ્ફ, પ્લેયરની બાજુમાં ભલામણોની દીવાલ, માઉસ સહેજ હલે કે તરત ચાલુ થતાં પ્રીવ્યૂ, «એક વીડિયો»ને એક કલાક બનાવી દેતાં થંબનેલ. YouTube Clean એ જગ્યા તમને પાછી આપે છે. સાઇડ પેનલ ખોલો, એક સ્વિચ ફેરવો — વધારાનું બધું તરત ગાયબ: પાનું રીલોડ નહીં, ખાતું નહીં, સેટઅપ નહીં.

60+ સ્વિચ, એક જ સાઇડ પેનલ, તાત્કાલિક પરિણામ. મફત, ઓપન સોર્સ, કોઈ ટ્રેકિંગ નહીં.

તમે શું શું સાફ કરી શકો

ફીડ અને ભલામણો. Shorts શેલ્ફ જ્યાં પણ દેખાય ત્યાં છુપાવો, સાથે મિક્સ અને પ્લેલિસ્ટ, «એક્સપ્લોર» અને «સમાચાર» બ્લોક તથા ફક્ત સભ્યો માટેના વીડિયો. કર્સર મૂકતાં શરૂ થતું ઓટો-પ્રીવ્યૂ બંધ કરો, સ્ક્રીન પર વધુ વીડિયો સમાય એ માટે કોમ્પેક્ટ મોડ ચાલુ કરો, અને જોઈ લીધેલા વીડિયો છુપાવો — હોમ, સબસ્ક્રિપ્શન, ચેનલ પેજ અને ભલામણોમાં અલગ અલગ.

વીડિયો પેજ. ટિપ્પણીઓ, પ્લેયરની બાજુના ભલામણ કરેલા વીડિયો, લાઇક/ડિસલાઇક પટ્ટી, ક્રિયા બટન, વર્ણન, લાઇવ ચેટ, વસ્તુઓ અને ટિકિટ, અંતિમ સ્ક્રીન કાર્ડ અને ચેનલની તસવીરો છુપાવો. વર્ણન વધુ ઝીણવટથી છૂટું પડે છે: AI વિભાગ (Gemini), ટ્રાન્સક્રિપ્ટ, ઉલ્લેખાયેલા લોકો, સંબંધિત વીડિયો, ચેનલ કાર્ડ, «આ કેવી રીતે બન્યું», પ્રકરણો અને એપિસોડ.

જાહેરાતો અને પ્રમોશન. YouTube બેનર, ફીડમાંના પ્રાયોજિત વીડિયો અને જાહેરાત માહિતી પેનલ છુપાવો, અને પ્રાયોગિક ઓટો-સ્કિપ ચાલુ કરો જેથી છોડી શકાય એવી જાહેરાતો જાતે જ નીકળી જાય.

પ્લેયર અને પ્લેબેક. ઝડપનું સ્લાઇડર સીધું પ્લેયર કંટ્રોલમાં ઉમેરો, Premium હોય તો ઊંચા બિટરેટને પ્રાધાન્ય આપો, H.264 કોડેક ફરજિયાત કરો (VP9 અને AV1 બ્લોક થશે) જેથી CPU ગરમ થવાને બદલે ગ્રાફિક્સ કાર્ડ ડીકોડ કરે, નબળા મશીન પર પ્લેબેક 30 fps સુધી મર્યાદિત કરો, અને મિની પ્લેયર, થિયેટર મોડ, સબટાઇટલ તથા ઓટોપ્લે બટન છુપાવો.

Shorts. Shorts રાખવા હોય તો તમારી શરતે રાખો: અલગ ઝડપ નિયંત્રણ અને આગળના પર આપોઆપ સ્વિચ.

સાઇડબાર અને નેવિગેશન. સાઇડબાર સંપૂર્ણ છુપાવો, અથવા એક-એક વસ્તુ કાપો — Shorts, મારી ચેનલ, ઇતિહાસ, પ્લેલિસ્ટ, તમારા વીડિયો, પછી જુઓ, ગમેલા વીડિયો, ફિલ્મો, ડાઉનલોડ, આખી સબસ્ક્રિપ્શન યાદી, ટ્રેન્ડિંગ, સંગીત, લાઇવ, ગેમિંગ, સમાચાર, રમતગમત, YouTube Premium / Music / Kids / Studio લિંક અને «વિશે» લિંક સાથેનું ફૂટર.

શોધ અને ચેનલ. શોધ પરિણામોમાં ચેનલ, સંબંધિત શોધ, માહિતી કાર્ડ અને ચેનલનું વીડિયો શેલ્ફ છુપાવો. ચેનલ પેજ પર બેનર અને જાતે ચાલતું ટ્રેલર દૂર કરો.

હેડર. વોઇસ સર્ચ અને વર્ચ્યુઅલ કીબોર્ડ બટન, શોધ ટૅગ, અપલોડ બટન અને સૂચનાઓ છુપાવો.

જેમને કંઈ ગોઠવવું નથી તેમના માટે પ્રીસેટ

હળવી સફાઈ માટે «લાઇટ», રોજિંદા વિક્ષેપ વગરના YouTube માટે «સંતુલિત», અને લગભગ બધું હટાવવા «મહત્તમ» પસંદ કરો. દરેક પ્રીસેટ સંપાદિત થઈ શકે અને ડિફોલ્ટ પર પાછું લાવી શકાય, અને «કસ્ટમ» તમે શૂન્યથી બનાવો છો. એક મિનિટ માટે અસલી YouTube જોઈએ તો કીબોર્ડ શોર્ટકટ આખું એક્સ્ટેન્શન ચાલુ-બંધ કરે છે.

ગોપનીયતા, સીધી વાત

ખાતું નહીં, સાઇન-ઇન નહીં, એનાલિટિક્સ નહીં, ટ્રેકિંગ નહીં, ડેટા સંગ્રહ નહીં. તમારી સેટિંગ્સ બ્રાઉઝરના લોકલ સ્ટોરેજમાં રહે છે અને ત્યાંથી ક્યારેય બહાર જતી નથી. આખો સોર્સ કોડ MIT લાઇસન્સ હેઠળ GitHub પર છે — અમારા શબ્દ પર ભરોસો કરવાની જરૂર નથી.

ઝડપી રહે એ માટે બનાવેલું

લગભગ દરેક વિકલ્પ બિલ્ડ વખતે શુદ્ધ CSS માં કમ્પાઇલ થાય છે, એટલે બ્રાઉઝ કરતી વખતે કોઈ ખર્ચ નથી. માત્ર થોડીક વર્તણૂક આધારિત સુવિધાઓ જ JavaScript ચલાવે છે. Manifest V3, કોઈ રિમોટ કોડ નહીં, પૃષ્ઠભૂમિમાં કોઈ ભાર નહીં.

શરૂઆત કેવી રીતે કરવી

એક્સ્ટેન્શન ઇન્સ્ટોલ કરો, તેના આઇકોન પર ક્લિક કરી YouTube ની બાજુમાં સાઇડ પેનલ ખોલો, પછી પ્રીસેટ પસંદ કરો અથવા સ્વિચ એક-એક કરીને ફેરવો. ખુલ્લા પાના પર ફેરફાર તરત લાગુ થાય છે.

Chrome, Opera, Edge, Brave અને અન્ય Chromium આધારિત બ્રાઉઝરમાં ચાલે છે.

વારંવાર પુછાતા પ્રશ્નો

આ એડ બ્લોકર છે? બરાબર એવું નથી. તે બેનર, ફીડમાંના પ્રાયોજિત કાર્ડ અને જાહેરાત પેનલ છુપાવે છે અને છોડી શકાય એવી જાહેરાતો આપોઆપ છોડી શકે છે (પ્રાયોગિક). સાચા એડ બ્લોકર સાથે પણ સરસ ચાલે છે.

આનાથી YouTube બગડશે? બધું જ વૈકલ્પિક અને પાછું વાળી શકાય એવું છે — સ્વિચ બંધ કરો અને તત્ત્વ તરત પાછું આવે છે.

ખાતું જોઈએ? ના. ઇન્સ્ટોલ કરો અને વાપરો.

ખરેખર મફત છે? હા: મફત અને ઓપન સોર્સ, કોઈ પેઇડ પ્લાન નહીં, કોઈ અપસેલ નહીં.
