# YouTube Clean: บล็อก Shorts ซ่อนวิดีโอแนะนำและโฆษณา

บล็อก YouTube Shorts ซ่อนวิดีโอแนะนำ ข้ามโฆษณา และลบทุกอย่างที่ดึงความสนใจของคุณ
ออกไป YouTube Clean เปลี่ยน YouTube ให้เป็นพื้นที่ที่สงบและไม่วอกแวก
ซึ่งคุณเป็นผู้ควบคุม

สวิตช์กว่า 60 รายการ แผงด้านข้างเดียว เห็นผลทันที ฟรี โอเพนซอร์ส ไม่ต้องมีบัญชี
ไม่มีการติดตาม ไม่เก็บข้อมูล

สิ่งที่คุณซ่อนหรือบล็อกได้

• Shorts: หน้าแรก ผลการค้นหา แถบด้านข้าง หน้าช่อง รายการในเมนู
• วิดีโอแนะนำ: หน้าแรก คอลัมน์ข้างวิดีโอ การ์ดหน้าจอปิดท้าย
• โฆษณา: ข้ามโฆษณาวิดีโออัตโนมัติ แบนเนอร์ วิดีโอสปอนเซอร์ในฟีด
• ความคิดเห็นและแชทสด
• มิกซ์ เพลย์ลิสต์ มาแรง สำรวจ และข่าว
• ชั้นสินค้าและบัตร แบนเนอร์และตัวอย่างช่อง
• การแสดงตัวอย่างอัตโนมัติเมื่อชี้เมาส์ และคำอธิบายวิดีโอที่ยืดยาว
• แถบด้านข้าง: ซ่อนทั้งหมดหรือทีละรายการ
• แถบบน: ค้นหาด้วยเสียง แป้นพิมพ์เสมือน แท็กค้นหา ปุ่มอัปโหลด การแจ้งเตือน
• ผลการค้นหา: การค้นหาที่เกี่ยวข้อง การ์ดข้อมูล ชั้นวิดีโอของช่อง

บล็อก YOUTUBE SHORTS และการเลื่อนไม่รู้จบ

วิดีโอสั้นคือกับดักความสนใจที่ใหญ่ที่สุดบน YouTube

YouTube Clean นำ Shorts ออกจากหน้าแรก ผลการค้นหา แถบด้านข้าง และหน้าช่อง
เพื่อไม่ให้การแวะดูสั้น ๆ กลายเป็นการเลื่อนดูเป็นชั่วโมง

อยากเก็บ Shorts ไว้ใช่ไหม ใช้ตัวควบคุมความเร็วเฉพาะของ Shorts และปิดการเลื่อนไป
รายการถัดไปอัตโนมัติ แล้ว Shorts หนึ่งรายการก็จะเป็นแค่หนึ่งรายการ ไม่ใช่ฟีดที่
ไม่มีวันจบ

ซ่อนวิดีโอแนะนำและความรกในฟีด

คุณเป็นคนตัดสินใจว่าอะไรอยู่ต่อและอะไรต้องไป

ซ่อนวิดีโอแนะนำ มิกซ์และเพลย์ลิสต์ ความคิดเห็น แชทสด การ์ดหน้าจอปิดท้าย
ชั้นสินค้าและบัตร การแจ้งเตือน และส่วนวิดีโอมาแรง

ลดสัญญาณรบกวนทางสายตาให้มากขึ้นอีก: ปิดการแสดงตัวอย่างเมื่อชี้เมาส์
ซ่อนแบนเนอร์และตัวอย่างช่อง และตัดคำอธิบายให้เหลือเฉพาะสิ่งที่คุณอ่านจริง ๆ

ข้ามโฆษณาและเนื้อหาสปอนเซอร์

โฆษณาวิดีโอจะถูกข้ามโดยอัตโนมัติทันทีที่ปุ่มข้ามปรากฏขึ้น

แบนเนอร์โฆษณา วิดีโอสปอนเซอร์ในฟีด และแผงโปรโมชันจะถูกซ่อนทั้งในฟีดและหน้ารับชม
การท่องดูจึงไม่สะดุด

YOUTUBE ที่ไม่วอกแวกเพื่อสมาธิและการเรียน

YouTube Clean เป็นเครื่องมือช่วยโฟกัสแบบนุ่มนวล ไม่ใช่ตัวบล็อกที่ก้าวร้าว

ไม่มีอะไรถูกลบจนกว่าคุณจะสั่ง และแผงด้านข้างที่เรียบง่ายเก็บทุกการตั้งค่าไว้ห่างแค่
คลิกเดียว ไม่มีบัญชี ไม่มีแดชบอร์ด ไม่มีการเตือนซ้ำซาก

หลายคนใช้เป็นเครื่องมือดิจิทัลดีท็อกซ์แบบเบา ๆ สำหรับ YouTube ที่เน้นการควบคุม
ไม่ใช่การห้าม

พรีเซ็ตในคลิกเดียว: เบา สมดุล กำหนดเอง

เริ่มจากพรีเซ็ตสำเร็จรูป Light สำหรับการจัดระเบียบแบบเบา ๆ Balanced สำหรับโหมด
โฟกัส หรือสร้างโปรไฟล์ Custom ของคุณเองทีละสวิตช์

สลับพรีเซ็ตเมื่อเปลี่ยนระหว่างการทำงานกับการพักผ่อน YouTube จะเป็นเครื่องมือเมื่อ
คุณต้องการ และหลบไปเมื่อคุณไม่ต้องการ

เลย์เอาต์กะทัดรัด: วิดีโอมากขึ้นต่อหนึ่งหน้าจอ

โหมดกะทัดรัดเปลี่ยนหน้าแรก ผลการค้นหา และวิดีโอแนะนำในหน้ารับชมให้เป็นรายการหรือ
กริดที่เป็นระเบียบ

เลื่อนน้อยลง ผลลัพธ์ต่อหน้าจอมากขึ้น และเลย์เอาต์ที่ในที่สุดก็ให้ความสำคัญกับ
จอใหญ่

แถบเลื่อนความเร็วและโปรแกรมเล่นที่สะอาดตา

ปรับความเร็วการเล่นอย่างละเอียดด้วยแถบเลื่อนในโปรแกรมเล่นโดยตรง รวมถึงตัวควบคุม
ความเร็วแยกต่างหากสำหรับ Shorts

จัดระเบียบโปรแกรมเล่นด้วยการซ่อนปุ่มมินิเพลเยอร์ โหมดโรงภาพยนตร์ และคำบรรยาย
และปิดสวิตช์เล่นอัตโนมัติ เพื่อไม่ให้วิดีโอถัดไปเริ่มเองโดยอัตโนมัติ

ค้นหา แถบบน และแถบด้านข้างที่สะอาดตา

ลดความซับซ้อนของแถบบนด้วยการซ่อนการค้นหาด้วยเสียง แป้นพิมพ์เสมือน แท็กค้นหา
ปุ่มอัปโหลด และการแจ้งเตือน

ตัดแถบด้านข้างซ้ายให้เหลือเฉพาะที่จำเป็น หรือซ่อนทั้งหมด รวมถึงคุณ ประวัติการดู
เพลย์ลิสต์ ดูภายหลัง วิดีโอที่ชอบ ช่องที่ติดตาม สำรวจ มาแรง เพลง สด เกม ข่าว
กีฬา Premium, YouTube Music, Kids, Studio และส่วนท้าย

จัดระเบียบผลการค้นหาด้วย: การค้นหาที่เกี่ยวข้อง การ์ดข้อมูล และชั้นวิดีโอของช่อง

ใครใช้ YOUTUBE CLEAN

• นักเรียนและนักวิจัยที่ต้องใช้ YouTube ดูบรรยาย ไม่ใช่ดู Shorts
• นักพัฒนาและนักเขียนที่ดูบทเรียนระหว่างทำงานแบบตั้งใจลึก
• ผู้เรียนภาษาที่ใช้แถบเลื่อนความเร็วกับวิดีโอยาว
• ผู้ปกครองที่อยากได้ YouTube ที่สงบขึ้นบนคอมพิวเตอร์ที่ใช้ร่วมกัน
• ทุกคนที่กำลังดิจิทัลดีท็อกซ์แต่ยังต้องใช้ YouTube ทำงานจริง

โอเพนซอร์ส เบา และเป็นส่วนตัว

YouTube Clean เป็นโอเพนซอร์สทั้งหมดและสร้างบน Manifest V3

ไม่มีบัญชี ไม่มีการติดตาม ไม่มีการวิเคราะห์ ไม่เก็บข้อมูล การตั้งค่าของคุณอยู่ใน
เบราว์เซอร์ของคุณ อ่านโค้ด รายงานปัญหา หรือขอฟีเจอร์ได้ที่ GitHub

คำถามที่พบบ่อย

บล็อก Shorts ได้ทั้งหมดไหม
ได้ Shorts สามารถลบออกจากหน้าแรก การค้นหา แถบด้านข้าง หน้าช่อง และเมนูซ้าย
คุณยังเก็บ Shorts ไว้และปิดเฉพาะการเลื่อนอัตโนมัติได้ด้วย

ลบโฆษณา YouTube ได้ไหม
โฆษณาวิดีโอจะถูกข้ามอัตโนมัติทันทีที่ข้ามได้ และแบนเนอร์ วิดีโอสปอนเซอร์ในฟีด
รวมถึงแผงโปรโมชันจะถูกซ่อน นี่คือเครื่องมือจัดระเบียบ YouTube ไม่ใช่ตัวบล็อก
โฆษณาระดับเครือข่าย

YouTube ส่วนที่เหลือยังใช้งานได้ปกติไหม
ได้ ทุกฟีเจอร์ปิดอยู่โดยค่าเริ่มต้น จะไม่มีอะไรเปลี่ยนจนกว่าคุณจะเปิดสวิตช์
และการปิดจะคืนค่า YouTube กลับทันที

เก็บข้อมูลของฉันไหม
ไม่ ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการวิเคราะห์ การตั้งค่าถูกบันทึกในเครื่อง
บนเบราว์เซอร์ของคุณ
