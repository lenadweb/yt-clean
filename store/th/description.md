YouTube Clean ซ่อน Shorts วิดีโอแนะนำ ความคิดเห็น และโฆษณา เพื่อให้บนหน้าเหลือแค่วิดีโอที่คุณตั้งใจมาดูจริง ๆ

YouTube ถูกออกแบบมาให้คุณเลื่อนต่อไปเรื่อย ๆ ทั้งชั้น Shorts ที่ไม่มีวันหมด กำแพงวิดีโอแนะนำข้างโปรแกรมเล่น ตัวอย่างที่เล่นเองเพียงเพราะเมาส์เลื่อนผ่าน และภาพขนาดย่อที่เปลี่ยน «วิดีโอเดียว» ให้กลายเป็นหนึ่งชั่วโมง YouTube Clean คืนพื้นที่นั้นให้คุณ เปิดแผงด้านข้าง กดสวิตช์เดียว ส่วนเกินหายทันที ไม่ต้องรีเฟรชหน้า ไม่ต้องมีบัญชี ไม่ต้องตั้งค่าอะไร

สวิตช์กว่า 60 รายการ แผงด้านข้างเดียว เห็นผลทันที ฟรี โอเพนซอร์ส ไม่มีการติดตาม

สิ่งที่คุณจัดการได้

ฟีดและวิดีโอแนะนำ ซ่อนชั้น Shorts ทุกที่ที่มันโผล่ขึ้นมา รวมถึงมิกซ์และเพลย์ลิสต์ บล็อก «สำรวจ» และ «ข่าว» และวิดีโอเฉพาะสมาชิก ปิดตัวอย่างอัตโนมัติเมื่อวางเมาส์ เปิดโหมดกะทัดรัดให้หน้าจอบรรจุวิดีโอได้มากขึ้น และซ่อนวิดีโอที่ดูไปแล้ว แยกกันได้ทั้งหน้าแรก การติดตาม หน้าช่อง และในวิดีโอแนะนำ

หน้าวิดีโอ ซ่อนความคิดเห็น วิดีโอแนะนำข้างโปรแกรมเล่น แถบชอบ/ไม่ชอบ ปุ่มการทำงาน คำอธิบาย แชทสด สินค้าและบัตร การ์ดหน้าจอปิดท้าย และรูปช่อง ส่วนคำอธิบายยังแยกย่อยได้อีก ทั้งส่วน AI (Gemini) ข้อความถอดเสียง บุคคลที่กล่าวถึง วิดีโอที่เกี่ยวข้อง การ์ดช่อง «สร้างขึ้นมาอย่างไร» บทและตอน

โฆษณาและโปรโมชัน ซ่อนแบนเนอร์ YouTube วิดีโอสปอนเซอร์ในฟีด และแผงข้อมูลโฆษณา แล้วเปิดการข้ามอัตโนมัติแบบทดลอง เพื่อให้โฆษณาที่ข้ามได้จัดการตัวเอง

โปรแกรมเล่นและการเล่น เพิ่มแถบเลื่อนความเร็วลงในแถบควบคุมโดยตรง เลือกบิตเรตที่สูงขึ้นเมื่อใช้ Premium บังคับใช้โคเดก H.264 (บล็อก VP9 และ AV1) ให้การ์ดจอถอดรหัสแทนที่จะปล่อยให้ซีพียูร้อน จำกัดการเล่นไว้ที่ 30 fps บนเครื่องที่อ่อนกว่า และซ่อนปุ่มมินิเพลเยอร์ โหมดโรงภาพยนตร์ คำบรรยาย และเล่นอัตโนมัติ

Shorts ถ้ายังเก็บ Shorts ไว้ ก็ให้เป็นไปตามกติกาของคุณ มีตัวควบคุมความเร็วแยกต่างหาก และเปลี่ยนไปคลิปถัดไปโดยอัตโนมัติ

แถบข้างและการนำทาง ซ่อนแถบข้างทั้งแถบ หรือเล็มทีละรายการ ทั้ง Shorts ช่องของฉัน ประวัติการเข้าชม เพลย์ลิสต์ วิดีโอของคุณ ดูภายหลัง วิดีโอที่ชอบ ภาพยนตร์ ดาวน์โหลด รายการการติดตามทั้งหมด มาแรง เพลง สด เกม ข่าว กีฬา ลิงก์ YouTube Premium / Music / Kids / Studio และส่วนท้ายพร้อมลิงก์ «เกี่ยวกับ»

การค้นหาและช่อง ซ่อนช่องในผลการค้นหา การค้นหาที่เกี่ยวข้อง การ์ดข้อมูล และชั้นวิดีโอของช่อง ในหน้าช่อง ให้เอาแบนเนอร์และตัวอย่างที่เล่นเองออก

แถบด้านบน ซ่อนปุ่มค้นหาด้วยเสียงและแป้นพิมพ์เสมือน แท็กการค้นหา ปุ่มอัปโหลด และการแจ้งเตือน

ค่าที่ตั้งไว้ล่วงหน้า สำหรับคนที่ไม่อยากปรับอะไรเลย

เลือก «เบา» สำหรับการเก็บกวาดแบบนุ่มนวล «สมดุล» สำหรับ YouTube ประจำวันที่ไม่มีสิ่งรบกวน หรือ «สูงสุด» เพื่อถอดออกเกือบทั้งหมด ทุกชุดแก้ไขได้และรีเซ็ตกลับค่าเริ่มต้นได้ ส่วน «กำหนดเอง» คุณสร้างเองตั้งแต่ต้น และมีคีย์ลัดเปิดปิดส่วนขยายทั้งตัว เวลาคุณอยากเห็น YouTube แบบเดิมสักครู่

ความเป็นส่วนตัว พูดกันตรง ๆ

ไม่มีบัญชี ไม่ต้องลงชื่อเข้าใช้ ไม่มีการวิเคราะห์ ไม่มีการติดตาม ไม่เก็บข้อมูล การตั้งค่าของคุณอยู่ในที่เก็บข้อมูลในเครื่องของเบราว์เซอร์และไม่เคยออกไปไหน ซอร์สโค้ดทั้งหมดอยู่บน GitHub ภายใต้สัญญาอนุญาต MIT คุณไม่ต้องเชื่อเราแค่คำพูด

สร้างมาให้ยังเร็วอยู่

เกือบทุกตัวเลือกถูกคอมไพล์เป็น CSS ล้วนตอนบิลด์ จึงไม่มีต้นทุนขณะคุณใช้งาน มีเพียงไม่กี่ฟีเจอร์เชิงพฤติกรรมที่รัน JavaScript Manifest V3 ไม่มีโค้ดจากระยะไกล ไม่มีภาระเบื้องหลัง

เริ่มต้นอย่างไร

ติดตั้งส่วนขยาย คลิกไอคอนเพื่อเปิดแผงด้านข้างข้าง ๆ YouTube แล้วเลือกชุดค่าที่ตั้งไว้ หรือกดสวิตช์ทีละอัน การเปลี่ยนแปลงมีผลกับหน้าที่เปิดอยู่ทันที

ใช้ได้กับ Chrome, Opera, Edge, Brave และเบราว์เซอร์อื่นที่ใช้ Chromium

คำถามที่พบบ่อย

นี่คือตัวบล็อกโฆษณาหรือเปล่า ไม่เชิง มันซ่อนแบนเนอร์ การ์ดสปอนเซอร์ในฟีด และแผงโฆษณา อีกทั้งข้ามโฆษณาที่ข้ามได้โดยอัตโนมัติ (ทดลอง) และใช้ร่วมกับตัวบล็อกโฆษณาจริง ๆ ได้โดยไม่มีปัญหา

มันจะทำให้ YouTube พังไหม ทุกอย่างเป็นทางเลือกและย้อนกลับได้ ปิดสวิตช์แล้วองค์ประกอบกลับมาทันที

ต้องมีบัญชีไหม ไม่ต้อง ติดตั้งแล้วใช้ได้เลย
