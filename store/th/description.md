บล็อก YouTube Shorts ทำความสะอาดวิดีโอแนะนำ และดูโดยมีสิ่งรบกวนน้อยลง YouTube Clean นำตัวกรองฟีด การซ่อนความคิดเห็น การข้ามโฆษณาแบบทดลอง และการควบคุมการเล่นมารวมกันในส่วนขยาย Chrome ฟรีเพียงหนึ่งเดียว เก็บวิดีโอที่คุณต้องการ ขจัดสิ่งยุ่งเหยิงรอบๆ และทำให้ไซต์ทำงานแทนคุณ

เลือกจากการตั้งค่ามากกว่า 70 รายการในแผงด้านข้างข้างวิดีโอของคุณ เริ่มต้นด้วยการตั้งค่าล่วงหน้าที่แก้ไขได้หรือปรับแต่งองค์ประกอบแต่ละรายการ: ฟีดหลัก การสมัครรับข้อมูล ผลการค้นหา หน้าดู โปรแกรมเล่น และการนำทางด้านซ้าย ฟรีและโอเพ่นซอร์ส โดยไม่มีบัญชี การสมัครสมาชิก หรือการติดตาม

คุณสมบัติโดยสรุป

• ลบชั้นวางวิดีโอสั้นและรายการการนำทางออก
• กรองวิดีโอที่ดู มิกซ์ เพลย์ลิสต์ และเนื้อหาสำหรับสมาชิกเท่านั้นออก
• ซ่อนความคิดเห็น แชทสด การ์ดตอนท้าย และแผงการโปรโมต
• ทำให้ภาพขนาดย่อเล็กลงด้วยฟีดขนาดกะทัดรัดและรูปแบบการค้นหา
• ปรับการเล่นจาก 0.25x เป็น 3x ด้วยแถบเลื่อนความเร็วในเครื่องเล่น
• เปิดหรือปิดการตั้งค่าการล้างข้อมูลด้วยแป้นพิมพ์ลัด

ซ่อนส่วน Shorts

กำลังมองหา Shorts blocker ที่ให้คุณใช้วิดีโอปกติต่อไปอยู่ใช่ไหม ซ่อนชั้นวางวิดีโอสั้นในฟีด ลบผลการค้นหาที่ตรงกัน และล้างรายการออกจากเมนูด้านซ้าย การตั้งค่าฟีดและการนำทางทำงานร่วมกันเพื่อลบจุดเข้าทั่วไปในการเลื่อนแนวตั้ง

ใช้ค่าที่ตั้งล่วงหน้าการล้างข้อมูลสำเร็จรูปหรือเปิดใช้งานสวิตช์ที่เกี่ยวข้องทีละรายการ คุณสามารถเก็บวิดีโอแบบยาว การสมัครรับข้อมูล และการค้นหาไว้ได้ในขณะที่ลบเนื้อหาแบบสั้นที่รบกวนการรับชมของคุณ การควบคุมเหล่านี้จะเปลี่ยนสิ่งที่ปรากฏในอินเทอร์เฟซ ลิงก์วิดีโอโดยตรงยังคงสามารถเข้าถึงได้

ซ่อนวิดีโอที่ดูจากฟีดวิดีโอของคุณ

เบื่อกับการเลื่อนดูวิดีโอที่ผ่านมาที่คุณเคยดูไปแล้วใช่ไหม? ลบวิดีโอที่ดูแยกจากหน้าแรก การสมัครรับข้อมูล หน้าช่อง และคำแนะนำหน้าสำหรับดู เปิดตัวกรองไว้ในฟีดการติดตามของคุณ แต่ปิดในช่องที่คุณต้องการกลับมาดูอีกครั้ง หรือใช้การตั้งค่าทั้งสี่ร่วมกัน

การตรวจจับจะใช้ตัวบ่งชี้ความคืบหน้าในการรับชมที่แสดงบนภาพขนาดย่อของวิดีโอ มันกรองหน้าที่มองเห็นได้โดยไม่ต้องลบประวัติการดูหรือทำเครื่องหมายวิดีโอว่าดูแล้ว วิดีโอที่ไม่มีตัวบ่งชี้ความคืบหน้าที่ตรงกันอาจยังคงมองเห็นได้

กรองคำแนะนำ มิกซ์และเพลย์ลิสต์

ให้พื้นที่สำหรับคำแนะนำที่เป็นประโยชน์โดยการกรองเนื้อหาบางประเภท ซ่อนมิกซ์และเพลย์ลิสต์ ลบวิดีโอสำหรับสมาชิกเท่านั้น และยกเลิกการบล็อกการสำรวจหรือข่าวสาร รวมตัวเลือกเหล่านี้เข้ากับตัวกรองวิดีโอที่รับชมเพื่อลดการแนะนำซ้ำและความยุ่งเหยิงของฟีด

สิ่งนี้ช่วยให้คุณควบคุมสิ่งที่ยังคงมองเห็นได้ในขณะที่ยังคงการค้นพบไว้ ส่วนขยายจะกรองประเภทเนื้อหาที่เลือก ไม่ได้แทนที่อัลกอริธึมการแนะนำหรือทำให้โฮมฟีดว่างเปล่าทั้งหมด

ซ่อนความคิดเห็น แชทสด และการ์ดตอนท้าย

ชมการบรรยายโดยไม่มีการสนทนาด้านล่างเพื่อแย่งชิงความสนใจของคุณ ซ่อนความคิดเห็นบนหน้าวิดีโอ ลบแชทสดระหว่างสตรีม และล้างการ์ด End Screen หรือทีเซอร์การ์ดเหนือโปรแกรมเล่น

คุณยังสามารถลบสินค้าและชั้นวางตั๋ว รวมถึงการควบคุมการกดชอบและไม่ชอบ ปุ่มการดำเนินการ และรูปภาพช่องได้ การตั้งค่าแต่ละรายการจะแยกจากกัน ดังนั้นหน้าสำหรับดูที่สะอาดตายิ่งขึ้นยังคงสามารถเก็บคำอธิบาย ปุ่มคำบรรยาย หรือองค์ประกอบอื่นๆ ที่คุณใช้ได้

ข้ามโฆษณาและซ่อนวิดีโอที่ได้รับการสนับสนุน

ขจัดความยุ่งเหยิงในการโฆษณาด้วยการซ่อนแบนเนอร์ การ์ดแสดงผลที่ได้รับการสนับสนุน และแผงข้อมูลโฆษณา การควบคุมเหล่านี้ทำงานแยกกัน คุณจึงสามารถเลือกได้ว่าองค์ประกอบส่งเสริมการขายใดจะหายไปจากหน้าการเรียกดูและการดูของคุณ

ตัวเลือกข้ามโฆษณาจะพยายามข้ามโฆษณาวิดีโอโดยอัตโนมัติ การข้ามอัตโนมัติเป็นการทดลอง: ลักษณะการทำงานขึ้นอยู่กับโปรแกรมเล่นปัจจุบันและรูปแบบโฆษณา เปิดใช้งานแยกกันเมื่อคุณต้องการลองข้ามโฆษณาอัตโนมัติ ไม่ใช่ตัวบล็อกโฆษณาระดับเครือข่ายและไม่รับประกันประสบการณ์การใช้งานแบบไม่มีโฆษณา

ปิดการแสดงตัวอย่างอัตโนมัติเมื่อชี้เมาส์

หยุดการย้ายตัวอย่างภาพขนาดย่อจากการเริ่มต้นเมื่อตัวชี้ของคุณผ่านวิดีโอ ปิดการแสดงตัวอย่างแบบโฮเวอร์เพื่อเรียกดูฟีดที่เงียบกว่าและคงที่มากขึ้น และอ่านชื่อเรื่องโดยไม่ต้องแสดงตัวอย่างเพื่อแย่งความสนใจของคุณ

การตั้งค่านี้ควบคุมลักษณะการทำงานของภาพขนาดย่อ ตัวเลือกแยกต่างหากในการซ่อนสวิตช์เล่นอัตโนมัติจะลบปุ่มนั้นออกจากเครื่องเล่นเท่านั้น มันไม่ได้ปิดการเล่นอัตโนมัติของวิดีโอถัดไป

ภาพขนาดย่อของวิดีโอที่เล็กลงและรูปแบบที่กะทัดรัด

ต้องการวิดีโอต่อหน้าจอมากขึ้นแทนที่จะเป็นภาพขนาดย่อขนาดใหญ่ใช่ไหม โหมดกะทัดรัดช่วยลดปริมาณภาพในฟีดหลัก ผลการค้นหา และคำแนะนำหน้าสำหรับดู การแสดงตัวอย่างที่เล็กลง การเว้นวรรคที่แคบลง และการจัดเรียงที่หนาแน่นยิ่งขึ้น ช่วยให้สแกนชื่อเรื่องและเปรียบเทียบผลลัพธ์ได้ง่ายขึ้น

ใช้ตารางขนาดกะทัดรัดเพื่อเรียกดูบทช่วยสอน ค้นหาตอนต่อไปของซีรีส์ หรือทำงานผ่านผลการค้นหาโดยมีการเลื่อนน้อยลง เลย์เอาต์เป็นการจัดเรียงที่กำหนดไว้ล่วงหน้า ดังนั้นคุณไม่จำเป็นต้องแก้ไข CSS หรือกำหนดค่าความกว้างคอลัมน์แต่ละคอลัมน์

แถบเลื่อนความเร็วการเล่น

ปรับความเร็วในการเล่นโดยตรงภายในเครื่องเล่นวิดีโอ ใช้แถบเลื่อนตั้งแต่ 0.25x ถึง 3x ปรับแบบละเอียดขั้นละ 0.05x หรือเลือกค่าที่ตั้งไว้ล่วงหน้า เช่น 1.25x, 1.5x, 2x หรือ 3x ความเร็วที่คุณเลือกจะถูกบันทึกไว้ในการตั้งค่าส่วนขยาย

ชะลอการออกเสียงในระหว่างการฝึกภาษา ทำตามการสาธิตโดยละเอียดตามที่คุณต้องการ หรือเร่งการบรรยายที่คุ้นเคย ตัวควบคุมความเร็วใช้ได้กับวิดีโอหน้าสำหรับดูปกติ คุณยังสามารถซ่อนปุ่มมินิเพลเยอร์ โรงละคร หรือคำบรรยายเพื่อให้ชุดควบคุมเครื่องเล่นทำได้ง่ายขึ้น

H.264, VP9, AV1, 60 fps, Enhanced Bitrate

การควบคุมการเล่นขั้นสูงช่วยให้คุณบังคับ H.264 โดยการบล็อก VP9 และ AV1 หรือบล็อกสตรีม 60 fps เมื่อคุณต้องการวิดีโอที่มีอัตราเฟรมต่ำ สิ่งนี้มีประโยชน์กับแล็ปท็อปและอุปกรณ์รุ่นเก่าที่มีการรองรับตัวแปลงสัญญาณที่จำกัด การถอดรหัสฮาร์ดแวร์ โหลด CPU และคุณภาพที่ใช้ได้ขึ้นอยู่กับอุปกรณ์ของคุณและสตรีมที่มีให้สำหรับวิดีโอแต่ละรายการ การบังคับใช้ H.264 สามารถจำกัดความละเอียดที่มีอยู่ได้

สมาชิกระดับพรีเมียมสามารถเลือกบิตเรตที่ปรับปรุงได้เมื่อมีตัวเลือกดังกล่าว การตั้งค่านี้จะเลือกตัวเลือกการเล่นที่มีอยู่และไม่ได้ปลดล็อคคุณสมบัติที่ต้องชำระเงิน การตั้งค่าทดลองเพิ่มเติมจะปรับประมาณการแบนด์วิธที่โปรแกรมเล่นใช้ ความเร็วการเชื่อมต่อจริงไม่เปลี่ยนแปลง

ซ่อนแถบด้านข้างและทำให้การนำทางง่ายขึ้น

ลบแถบนำทางด้านซ้ายออกทั้งหมดหรือตัดรายการเมนูแต่ละรายการ เลือกสิ่งที่จะมองเห็นได้ในประวัติ เพลย์ลิสต์ ดูภายหลัง วิดีโอที่ชอบ ดาวน์โหลด การสมัครรับข้อมูล กำลังมาแรง เพลง เกม ข่าวสาร และส่วนอื่น ๆ ล้างลิงก์ส่วนท้ายเมื่อคุณต้องการนำทางไปยังเนื้อหาของคุณน้อยลง

ลดความซับซ้อนของแถบด้านบนด้วย: ซ่อนการแจ้งเตือน ปุ่มอัปโหลด ค้นหาด้วยเสียง ปุ่มแป้นพิมพ์เสมือน หรือแท็กค้นหา นี่คือการตั้งค่าการมองเห็น พวกเขาจะไม่ลบเพลย์ลิสต์ การสมัครรับข้อมูล หรือเนื้อหาบัญชีของคุณ

ล้างผลการค้นหาและหน้าช่อง

ทำให้การสแกนผลการค้นหาง่ายขึ้นโดยการซ่อนการ์ดผลลัพธ์ของช่อง คำแนะนำการค้นหาที่เกี่ยวข้อง การ์ดข้อมูล หรือชั้นวางวิดีโอของช่อง จับคู่ตัวควบคุมเหล่านั้นกับโหมดกะทัดรัดเมื่อคุณต้องการหน้าผลลัพธ์ที่หนาแน่นยิ่งขึ้น

บนหน้าช่อง ให้ซ่อนแบนเนอร์และตัวอย่างช่อง เรียกดูวิดีโอที่คุณพบโดยมีองค์ประกอบตกแต่งน้อยลงและมีการขัดจังหวะน้อยลงจากตัวอย่างที่โดดเด่น

เลือกส่วนคำอธิบายวิดีโอที่จะแสดง

ซ่อนคำอธิบายทั้งหมดหรือเลือกแต่ละส่วน ตัวเลือกต่างๆ ครอบคลุมถึงสรุป AI, บทถอดเสียง, บุคคลที่กล่าวถึง, วิดีโอที่เกี่ยวข้อง, การ์ดช่อง "วิธีการสร้างสิ่งนี้" และบทหรือตอนต่างๆ

ให้มองเห็นข้อความถอดเสียงและบทต่างๆ เพื่อการเรียนรู้ หรือลบออกเมื่อคุณต้องการคำอธิบายที่สั้นกว่านี้ การควบคุมเหล่านี้จะซ่อนส่วนของหน้าที่มีอยู่ พวกเขาไม่ได้สร้างบทสรุป เขียนบทถอดเสียงใหม่ หรือเปลี่ยนแปลงเนื้อหาของผู้สร้าง

YouTube ที่ไร้สิ่งรบกวนสำหรับการเรียนและการทำงานที่มีสมาธิ

สร้างการตั้งค่าการรับชมที่มุ่งเน้นเกี่ยวกับวิธีการใช้งานไซต์ของคุณ:

• นักเรียน: ลดปัญหาอาหารเกะกะขณะดูบทเรียนหรือเตรียมตัวสอบ
• นักพัฒนาและนักวิจัย: เก็บบทแนะนำและการสาธิตไว้ใกล้มือระหว่างการทำงานเชิงลึก
• ผู้เรียนภาษา: รวมหน้าที่เงียบกว่าเข้ากับการปรับความเร็วที่แม่นยำ
• ผู้ชมขาประจำ: ทำให้การสมัครรับข้อมูลง่ายต่อการเรียกดูและลดคำแนะนำซ้ำ
• มินิมัลลิสต์แบบดิจิทัล: ขจัดสัญญาณรบกวนทางภาพและทำให้การดูโดยเจตนาเป็นส่วนหนึ่งของกิจวัตรดีท็อกซ์แบบดิจิทัล

เลือก เบา สำหรับการล้างข้อมูลขนาดเล็ก หรือ สมดุล สำหรับชุดตัวกรองที่กว้างขึ้น ค่าที่ตั้งล่วงหน้าทั้งสองสามารถแก้ไขและรีเซ็ตได้ กำหนดเอง เริ่มต้นด้วยการปิดสวิตช์การล้างข้อมูล เพื่อให้คุณสร้างการกำหนดค่าของคุณเองได้ ค่าที่ตั้งล่วงหน้า สมดุล จะถูกเลือกเป็นค่าเริ่มต้นในการติดตั้ง

สลับการตั้งค่าแต่ละรายการตามความต้องการของคุณ หรือใช้แป้นพิมพ์ลัดของส่วนขยายเพื่อเปิดและปิดการกำหนดค่าทั้งหมด ไม่มีการบังคับจับเวลาโฟกัส โควต้าการใช้งาน หรือเซสชันการศึกษาที่ถูกล็อค

ฟรีและโอเพ่นซอร์สพร้อมการตั้งค่าในเครื่อง

การตั้งค่าส่วนขยายทั้งหมดสามารถใช้ได้โดยไม่ต้องชำระเงินหรือลงทะเบียน ไม่มีการสมัครสมาชิก การนับถอยหลังการทดลองใช้ การวิเคราะห์ หรือการเก็บข้อมูลส่วนบุคคล การตั้งค่าจะถูกจัดเก็บไว้ในเบราว์เซอร์ของคุณ ซอร์สโค้ดแบบเต็มมีอยู่ใน GitHub ภายใต้ใบอนุญาต MIT

ออกแบบมาสำหรับเว็บไซต์เดสก์ท็อปใน Chrome พร้อมอินเทอร์เฟซใน 52 ภาษา มันไม่ได้แก้ไขแอพมือถือ การล้างข้อมูลอินเทอร์เฟซส่วนใหญ่ใช้ CSS; การเล่นและคุณสมบัติโต้ตอบอื่น ๆ ใช้ JavaScript ในเครื่อง

เริ่มต้นในสามขั้นตอน

1. เพิ่ม YouTube Clean ลงใน Chrome และเปิดเว็บไซต์
2. คลิกไอคอนส่วนขยายเพื่อเปิดแผงด้านข้าง
3. เลือกค่าที่ตั้งล่วงหน้า จากนั้นปรับฟีด การนำทาง และการตั้งค่าการเล่นที่คุณต้องการ

การเปลี่ยนแปลงการมองเห็นอินเทอร์เฟซจะมีผลเมื่อคุณสลับการเปลี่ยนแปลง ปักหมุดส่วนขยายไว้ที่แถบเครื่องมือเพื่อให้เข้าถึงส่วนควบคุมได้ง่าย หากองค์ประกอบของหน้าเปลี่ยนแปลงและตัวกรองหยุดการจับคู่ ให้รายงานปัญหาเพื่อให้สามารถตรวจสอบได้
