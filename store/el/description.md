Παράβλεψη διαφημίσεων και απόκρυψη βίντεο με χορηγία

Ξεκαθαρίστε τη διαφημιστική ακαταστασία κρύβοντας banner, κάρτες βίντεο με χορηγία και πάνελ πληροφοριών διαφημίσεων. Αυτά τα στοιχεία ελέγχου λειτουργούν χωριστά, ώστε να μπορείτε να επιλέξετε ποια διαφημιστικά στοιχεία εξαφανίζονται από τις σελίδες περιήγησης και προβολής.

Η αυτόματη παράβλεψη είναι πειραματική: η συμπεριφορά της εξαρτάται από το τρέχον πρόγραμμα αναπαραγωγής και τη μορφή διαφήμισης. Ενεργοποιήστε το ξεχωριστά όταν θέλετε να δοκιμάσετε την αυτόματη παράβλεψη διαφημίσεων. Απενεργοποίηση αυτόματης προεπισκόπησης

Σταματήστε να ξεκινούν οι προεπισκοπήσεις μικρογραφιών όταν ο δείκτης περνάει πάνω από ένα βίντεο. Απενεργοποιήστε τις προεπισκοπήσεις με το δείκτη του ποντικιού για να περιηγηθείτε σε μια πιο αθόρυβη, πιο στατική ροή και να διαβάσετε τίτλους χωρίς προεπισκόπηση να ανταγωνίζεται την προσοχή σας.

Αυτή η ρύθμιση ελέγχει τη συμπεριφορά των μικρογραφιών. Η ξεχωριστή επιλογή για απόκρυψη του διακόπτη αυτόματης αναπαραγωγής αφαιρεί μόνο αυτό το κουμπί από τη συσκευή αναπαραγωγής. δεν απενεργοποιεί την αυτόματη αναπαραγωγή επόμενου βίντεο.

Μικρότερες μικρογραφίες βίντεο και συμπαγής διάταξη

Χρησιμοποιήστε το συμπαγές πλέγμα για να περιηγηθείτε σε σεμινάρια, να βρείτε το επόμενο επεισόδιο μιας σειράς ή να εργαστείτε στα αποτελέσματα αναζήτησης με λιγότερη κύλιση. Η διάταξη είναι μια προκαθορισμένη διάταξη, επομένως δεν χρειάζεται να επεξεργαστείτε CSS ή να διαμορφώσετε μεμονωμένα πλάτη στηλών.

Ρυθμιστικό ταχύτητας αναπαραγωγής

Ρυθμίστε την ταχύτητα αναπαραγωγής απευθείας μέσα στο πρόγραμμα αναπαραγωγής βίντεο. Χρησιμοποιήστε ένα ρυθμιστικό από 0,25x σε 3x, βελτιστοποιήστε σε βήματα 0,05x ή επιλέξτε μια προεπιλογή όπως 1,25x, 1,5x, 2x ή 3x. Η επιλεγμένη ταχύτητα αποθηκεύεται στις ρυθμίσεις επέκτασης.

Επιβραδύνετε την προφορά κατά τη διάρκεια της γλωσσικής πρακτικής, ακολουθήστε μια λεπτομερή επίδειξη με τον δικό σας ρυθμό ή επιταχύνετε μια οικεία διάλεξη. Ο ελεγκτής ταχύτητας είναι διαθέσιμος για βίντεο κανονικής σελίδας παρακολούθησης. Μπορείτε επίσης να αποκρύψετε τα κουμπιά του miniplayer, του θεάτρου ή των υπότιτλων για ένα απλούστερο σύνολο στοιχείων ελέγχου του προγράμματος αναπαραγωγής.

H.264, VP9, AV1, 60 fps, Enhanced Bitrate

Τα προηγμένα χειριστήρια αναπαραγωγής σάς επιτρέπουν να επιβάλλετε το H.264 αποκλείοντας τα VP9 και AV1 ή να αποκλείετε ροές 60 fps όταν προτιμάτε βίντεο με χαμηλότερο ρυθμό καρέ. Αυτό μπορεί να είναι χρήσιμο σε παλαιότερους φορητούς υπολογιστές και συσκευές με περιορισμένη υποστήριξη κωδικοποιητή. Η αποκωδικοποίηση υλικού, το φορτίο της CPU και η διαθέσιμη ποιότητα εξαρτώνται από τη συσκευή σας και τις ροές που προσφέρονται για κάθε βίντεο. Η επιβολή H.264 μπορεί να περιορίσει τη διαθέσιμη ανάλυση.

Οι συνδρομητές Premium μπορούν να προτιμήσουν τον Ενισχυμένο ρυθμό μετάδοσης bit όταν αυτή η επιλογή είναι διαθέσιμη. Αυτή η ρύθμιση επιλέγει μια υπάρχουσα επιλογή αναπαραγωγής και δεν ξεκλειδώνει τις λειτουργίες επί πληρωμή. Μια πρόσθετη πειραματική ρύθμιση προσαρμόζει την εκτίμηση εύρους ζώνης που χρησιμοποιείται από το πρόγραμμα αναπαραγωγής. Η πραγματική ταχύτητα σύνδεσης παραμένει αμετάβλητη.
