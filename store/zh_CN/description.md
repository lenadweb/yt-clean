# YouTube Clean — 隐藏 Shorts、移除推荐、专注与数字排毒

让 YouTube 更安静、更干净，也更容易专注。

YouTube Clean 把 YouTube 变成一个平静、有意识、真正由你掌控的空间。

它移除那些抢走注意力的东西——Shorts、推荐、广告、评论和界面杂乱——
让你看完想看的内容就可以离开。

YouTube Clean 提供 60 多个开关，让你彻底自定义 YouTube 的外观和行为：
从信息流布局、内容清理，到播放器控件、播放速度和专注预设。
所有功能都是可选的，开启后立即生效，关闭同样迅速。

🧩 掌控 Shorts 与无尽滑动

短视频是最容易吞掉注意力的陷阱之一。

YouTube Clean 可以在首页信息流、搜索结果、侧边栏和频道页中隐藏 Shorts，
让「随便看看」不再变成一小时的滑动。

想保留它们？使用专门的 Shorts 速度控制，并关闭自动播放下一条，
让一条 Shorts 就只是一条 Shorts。

🧹 干净的 YouTube，更少噪音

留下什么、去掉什么，由你决定。

当推荐内容、混合列表与播放列表、评论、直播聊天、片尾卡片、周边与门票栏、
通知和热门板块干扰你时，都可以一并移除。

减少视觉噪音：关闭悬停自动预览，隐藏频道横幅和预告片，
把简介精简到你真正会读的部分。

🚫 更少广告，更少打断

视频广告在可跳过时会被自动跳过。

广告横幅、信息流中的赞助视频和推广信息面板会在信息流和观看页中隐藏，
浏览不再被打断。

🧠 更平静的专注体验

YouTube Clean 是温和的专注工具，而不是强硬的拦截器。

在你主动开启之前不会移除任何内容，简洁的侧边面板让每个设置都只需一次点击：
无需账号，没有复杂面板，也不会反复打扰你。

很多人把它当作 YouTube 的轻量数字排毒工具：重点在于掌控，而不是禁止。

⏱ 效率与有意识的观看

可以从现成预设开始——Light 做轻度清理，Balanced 面向专注场景——
也可以逐项打造属于自己的自定义配置。

在工作和休息之间切换预设：需要时它是工具，不需要时它安静退开。

📐 更紧凑的布局，一屏看更多

紧凑模式会把首页信息流、搜索结果和观看页推荐变成整齐的列表或网格。

滑动更少，一屏内容更多，布局终于对得起大尺寸显示器。

🎥 升级的播放器与播放体验

用播放器内的速度滑块精细调节播放速度。

隐藏迷你播放器、影院模式和字幕按钮，整理播放器控件；
关闭自动播放开关，下一个视频就不会自己开始。

🔎 搜索、顶栏与侧边栏清理

隐藏语音搜索、虚拟键盘、搜索标签、上传按钮和通知，让顶部栏更简洁。

把左侧边栏精简到必要项目——或者完全隐藏——包括「我」、历史记录、播放列表、
稍后观看、顶过的视频、订阅内容、探索、时下流行、Music、直播、游戏、新闻、
体育、Premium、YouTube Music、Kids、Studio 以及页脚。

搜索结果同样可以清理：相关搜索、信息卡片和频道栏。

🔓 开源、轻量、注重隐私

YouTube Clean 完全开源。

无需账号，不做追踪，不收集数据——你的设置只保存在浏览器里。
欢迎在 GitHub 上查看代码、反馈问题或提出功能建议。

🌍 在你观看的地方都能用

YouTube Clean 支持 Chrome 和 Opera，作用于整个站点：
首页信息流、搜索、观看页、频道和播放器。

让 YouTube 适应你，而不是反过来。

非常适合学习、深度工作、资料查阅、语言学习、网课、教程和长视频观看。
