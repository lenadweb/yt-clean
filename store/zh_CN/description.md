YouTube Clean 隐藏 Shorts、推荐、评论和广告，让页面上只剩下你真正想看的那个视频。

YouTube 天生就是为了让你一直刷下去：没完没了的 Shorts 货架、播放器旁边那堵推荐墙、鼠标一扫就自动播放的预览、把"就看一个"变成一小时的封面图。YouTube Clean 把这块空间还给你。打开侧边栏，拨一个开关，多余的东西立刻消失——不用刷新页面，不用账号，不用配置。

60 多个开关，一个侧边栏，即时生效。免费、开源、不做追踪。

可以清理什么

首页与推荐。在任何位置隐藏 Shorts 版块，隐藏合辑与播放列表、"探索"和"新闻"板块、会员专属视频。关闭悬停自动预览，打开紧凑模式让一屏放下更多视频，并隐藏已看过的视频——首页、订阅内容、频道页和推荐可以分别设置。

视频页。隐藏评论、播放器旁的推荐视频、点赞/不喜欢、操作按钮、简介、实时聊天、商品与门票、片尾卡片和频道头像。简介还能继续拆开：AI 板块（Gemini）、字幕文稿、提到的人物、相关视频、频道卡片、"制作方式"、章节与剧集。

广告与推广。隐藏 YouTube 横幅、信息流中的赞助视频和广告信息面板，再打开实验性的自动跳过，可跳过的广告就会自己解决。

播放器与播放。把倍速滑块直接加进播放器控制条；开通 Premium 时优先使用增强比特率；强制 H.264 编解码（屏蔽 VP9 和 AV1），让显卡硬解而不是让 CPU 发烫；在配置较弱的机器上限制为 30 fps；隐藏迷你播放器、影院模式、字幕和自动播放按钮。

Shorts。如果你还留着 Shorts，那就按你的规则来：独立的速度控制，以及自动切换到下一个 Short。

侧边栏与导航。可以整条隐藏侧边栏，也可以逐项修剪——Shorts、我的频道、历史记录、播放列表、你的视频、稍后观看、顶过的视频、电影、下载内容、整份订阅列表、时下流行、音乐、直播、游戏、新闻、体育，以及 YouTube Premium / Music / Kids / Studio 链接和带"关于"链接的页脚。

搜索与频道。隐藏搜索结果中的频道、相关搜索、搜索信息卡片和频道视频货架。在频道页上去掉横幅和会自动播放的预告片。

顶栏。隐藏语音搜索和虚拟键盘按钮、搜索标签、上传按钮和通知。

给不想调设置的人准备的预设

想温和收拾一下就选"轻度"，想要日常无干扰的 YouTube 就选"均衡"，想几乎全部清空就选"最大"。每个预设都可编辑、可一键恢复默认，"自定义"则完全由你从零搭建。快捷键能一键开关整个扩展，临时需要原版 YouTube 时很方便。

隐私，直说

不要账号，不用登录，没有分析统计，没有追踪，不收集数据。设置保存在浏览器本地存储里，从不外传。完整源代码以 MIT 许可证公开在 GitHub，不用只听我们说。

为速度而造

几乎所有选项都在构建时编译成纯 CSS，浏览时零开销。只有少数需要行为逻辑的功能才运行 JavaScript。Manifest V3，无远程代码，无后台负担。

如何开始

安装扩展，点击图标在 YouTube 旁打开侧边栏，然后选一个预设或逐个拨动开关。改动会立即应用到当前页面。

支持 Chrome、Opera、Edge、Brave 及其他基于 Chromium 的浏览器。

常见问题

它是广告拦截器吗？不完全是。它会隐藏横幅、信息流赞助卡片和广告信息面板，也能自动跳过可跳过的广告（实验性）。与专门的广告拦截器同时使用没有冲突。

会不会把 YouTube 弄坏？所有功能都需要你主动开启，而且可逆——关掉开关，元素立刻回来。

需要账号吗？不需要。装上就能用。

真的免费吗？是的：免费且开源，没有付费版，也没有推销。

有什么没按你想要的方式隐藏？到 GitHub 提个 issue——功能列表就是靠用户需求长出来的。
