屏蔽 YouTube Shorts，整理推荐内容，减少观看时的干扰。YouTube Clean 将信息流过滤、隐藏评论、实验性广告跳过和播放控制整合到一个免费的 Chrome 扩展中。保留想看的视频，移除周围多余的内容，让页面更符合你的使用习惯。

在视频旁的侧边面板中使用 70 多项设置。可以选择预设，也可以分别调整首页、订阅、搜索结果、观看页面、播放器和左侧导航。免费、开源，无需注册或付费订阅，不进行跟踪。

主要功能一览

• 隐藏短视频版块及对应的导航入口。
• 过滤已观看视频、合辑、播放列表和会员专享内容。
• 隐藏评论、直播聊天、片尾卡片和推广面板。
• 使用紧凑布局，缩小首页和搜索结果中的视频缩略图。
• 通过播放器内的滑块，将速度调整为 0.25 倍至 3 倍。
• 使用键盘快捷键开启或关闭整套清理设置。

屏蔽 Shorts，减少无休止的滚动

想隐藏短视频，同时继续观看普通视频？可以隐藏信息流中的短视频版块、搜索结果中的相关条目，以及左侧菜单中的入口。配合使用信息流和导航设置，可以减少进入短视频连续滚动的常见途径。

使用现成预设，或单独开启所需选项。移除分散注意力的短视频内容时，长视频、订阅和搜索仍然可用。这些设置改变界面中的显示内容，并不会阻止通过直接链接打开视频。

从信息流中隐藏已观看视频

不想反复看到已经看过的内容？可以分别在首页、订阅、频道页面和观看页面的推荐列表中隐藏已观看视频。例如，只清理订阅列表，保留频道页面中想重温的视频；也可以同时启用全部四项设置。

扩展根据视频缩略图上的观看进度条判断内容是否符合过滤条件。它只过滤页面显示，不会删除观看记录，也不会把视频标记为已观看。没有匹配进度条的视频可能仍然显示。

整理推荐、合辑和播放列表

通过过滤特定类型的内容，为有用的推荐留出空间。可以隐藏合辑、播放列表、会员专享视频，以及探索或新闻版块。结合已观看视频过滤功能，减少重复推荐和信息流中的杂乱内容。

你可以决定保留什么，同时继续发现新视频。扩展过滤选定的内容类型，不会替换推荐算法，也不会清空整个首页信息流。

隐藏评论、直播聊天和片尾卡片

观看课程时，不必让下方的讨论分散注意力。可以隐藏视频评论和直播聊天，移除播放器上的片尾卡片及卡片提示。

还可以隐藏商品与票务版块、赞与踩、操作按钮和频道头像。每项设置都相互独立，因此可以保留简介、字幕按钮等常用元素，同时简化观看页面。

跳过广告，隐藏推广视频

隐藏横幅广告、推广视频卡片和广告信息面板，减少页面上的广告内容。各项设置独立运行，你可以选择搜索和观看页面中需要隐藏的推广元素。

可选的自动跳过功能会尝试跳过视频广告。该功能处于实验阶段，效果取决于当前播放器和广告格式，需要单独开启。它不是网络层广告拦截器，不能保证完全无广告。

关闭鼠标悬停时的自动预览

不再让鼠标经过视频时自动开始播放预览。关闭悬停预览后，可以在更安静、静态的信息流中浏览标题，减少动态画面的干扰。

此设置控制缩略图预览。另一个隐藏自动播放开关的选项只会移除播放器中的按钮，不会关闭下一个视频的自动播放。

更小的缩略图与紧凑布局

想在一屏内看到更多视频，而不是过大的封面？紧凑模式可以调整首页、搜索结果和观看页面推荐列表的布局。较小的缩略图、较窄的间距和更密集的排列，让浏览标题和比较结果更方便。

用紧凑网格查找教程、寻找下一集或浏览搜索结果，减少滚动操作。这是一套现成布局，无需编辑 CSS，也无需手动设置每一列的宽度。

视频速度控制：慢放或加速至 3 倍

直接在播放器内调整速度。滑块范围为 0.25 倍至 3 倍，可以按 0.05 倍的步长微调，也可以选择 1.25 倍、1.5 倍、2 倍或 3 倍等预设。所选速度会保存在扩展设置中。

学习语言时放慢语速，按自己的节奏理解操作演示，或加速观看熟悉的课程。速度控制适用于普通观看页面中的视频。也可以隐藏迷你播放器、影院模式或字幕按钮，让控制区域更简洁。

H.264、60 fps 与增强比特率设置

高级播放选项可以通过屏蔽 VP9 和 AV1 来强制使用 H.264，也可以屏蔽 60 fps 视频流，改用较低帧率。这可能适合老旧笔记本电脑或解码支持有限的设备。硬件解码、CPU 占用和可用画质取决于设备及视频提供的流；强制 H.264 可能限制可选分辨率。

Premium 订阅用户可以在选项可用时优先使用增强比特率。这只是选择已有的播放画质，不会解锁付费功能。另一个实验性选项可以调整播放器使用的带宽估计值，但不会改变实际网速。

隐藏侧边栏，简化导航

可以隐藏整个左侧导航菜单，也可以只移除部分条目。自行决定是否显示历史记录、播放列表、稍后观看、喜欢的视频、下载、订阅、热门、音乐、游戏、新闻等入口，也可以隐藏菜单底部的链接。

顶部栏也能精简：隐藏通知、上传按钮、语音搜索、虚拟键盘按钮或搜索标签。这些选项只改变显示状态，不会删除播放列表、订阅或账号内容。

清理搜索结果和频道页面

隐藏搜索结果中的频道卡片、相关搜索建议、信息卡片和频道视频版块，让结果更容易浏览。与紧凑模式搭配使用，可以在屏幕上容纳更多内容。

在频道页面中隐藏横幅和频道预告片，减少大型装饰元素及预告视频带来的干扰，直接寻找想看的内容。

只保留需要的视频简介部分

隐藏整个简介，或单独选择各个部分，包括 AI 摘要、文字稿、提及的人物、相关视频、频道卡片、制作方式说明，以及章节或集数。

学习时保留文字稿和章节，或将其隐藏以缩短简介。这些设置只隐藏现有页面元素，不会生成摘要、改写文字稿或更改创作者的内容。

用于学习和专注工作的无干扰 YouTube

根据使用场景搭配设置：

• 学生：观看课程或备考时，减少信息流中的杂乱内容。
• 开发者和研究人员：专注工作时，仍能方便地查看教程和演示。
• 语言学习者：结合简洁页面与精细的速度调整。
• 日常观众：更方便地浏览订阅，减少重复推荐。
• 数字极简主义者：减少视觉噪音，把有意识的观看融入数字减负习惯。

选择“轻度”进行基本清理，或选择“平衡”启用更多过滤选项。两种预设都可以编辑和重置。“自定义”的清理开关初始为关闭状态，方便从头配置。安装后默认使用“平衡”预设。

根据需要调整单个设置，或使用键盘快捷键开启和关闭整套配置。没有强制专注计时器、使用额度或锁定的学习时段。

免费、开源，不收集个人数据

所有扩展设置无需付款或注册即可使用。没有订阅、试用倒计时或自动使用情况跟踪。首选项存储在本地浏览器中。如果您选择发送反馈，您的消息和扩展版本将通过 PostHog 发送给开发人员。没有附加浏览历史记录或帐户详细信息。完整的源代码可在 MIT 许可下在 GitHub 上获取。

适用于 Chrome 中的桌面版网站，界面支持 52 种语言，不修改移动应用。大部分界面清理通过 CSS 实现；播放和其他交互功能使用本地 JavaScript。

三个步骤开始使用

1. 在 Chrome 中安装 YouTube Clean 并打开网站。
2. 点击扩展图标，打开侧边面板。
3. 选择预设，再调整信息流、导航和播放选项。

切换设置时，界面元素的显示状态会随之变化。可以将扩展固定到工具栏，方便随时打开。如果网站更新后某个过滤器失效，请反馈问题以便检查。
