# YouTube Clean: 屏蔽 Shorts、隐藏推荐与广告

屏蔽 YouTube Shorts，隐藏推荐，自动跳过广告，并清除其他分散注意力的元素。
YouTube Clean 把 YouTube 变成一个安静、无干扰、由你掌控的空间。

60+ 个开关，一个侧边面板，即时生效。免费、开源，无需账号，无跟踪，不收集数据。

可隐藏或屏蔽的内容

• Shorts：首页、搜索结果、侧栏、频道页、左侧菜单项
• 推荐：首页、观看页侧栏、片尾卡片
• 广告：视频广告自动跳过、横幅广告、信息流赞助视频
• 评论和实时聊天
• 混合列表、播放列表、热门、探索和新闻
• 周边和门票货架、频道横幅与预告片
• 悬停自动预览和冗长的视频简介
• 侧栏：整体隐藏或逐项隐藏
• 顶栏：语音搜索、虚拟键盘、搜索标签、上传按钮、通知
• 搜索结果：相关搜索、信息卡片、频道货架

屏蔽 YOUTUBE SHORTS 和无限滚动

短视频是 YouTube 上最大的注意力陷阱。

YouTube Clean 会从首页、搜索结果、侧栏和频道页移除 Shorts，让“只看一会儿”不再
变成一小时的滑动。

想保留 Shorts？使用专门的 Shorts 速度控制并关闭自动播放下一条，这样一条 Shorts
就只是一条，而不是无尽的信息流。

隐藏推荐和信息流杂乱内容

留下什么、去掉什么，由你决定。

隐藏推荐视频、混合列表和播放列表、评论、实时聊天、片尾卡片、周边与门票货架、
通知以及热门板块。

进一步降低视觉噪音：关闭悬停自动预览，隐藏频道横幅和预告片，把简介精简到你真正
会读的内容。

跳过广告和赞助内容

视频广告在“跳过”按钮出现的一刻就会被自动跳过。

横幅广告、信息流中的赞助视频和推广信息面板会在首页和观看页被隐藏，浏览不再被
打断。

面向专注与学习的无干扰 YOUTUBE

YouTube Clean 是温和的专注工具，而不是激进的屏蔽器。

在你主动开启之前不会移除任何内容，安静的侧边面板让每个设置都只有一步之遥：无需
账号，无需仪表盘，没有反复的提醒。

很多人把它当作 YouTube 的轻量数字排毒工具，重点在于掌控，而不是禁止。

一键预设：轻度、平衡、自定义

从现成预设开始。Light 用于温和清理，Balanced 用于专注设置，或者逐项开关搭建你
自己的 Custom 配置。

在工作和休息之间切换预设：需要时 YouTube 是工具，不需要时它不来打扰。

紧凑布局：一屏显示更多视频

紧凑模式把首页、搜索结果和观看页推荐变成整齐的列表或网格。

滚动更少，每屏结果更多，布局终于开始善待大显示器。

播放速度滑块与整洁播放器

在播放器内用滑块精细调节播放速度，Shorts 还有独立的速度控制。

隐藏迷你播放器、影院模式和字幕按钮来整理播放器，并关闭自动播放开关，让下一个
视频永远不会自己开始。

清爽的搜索、顶栏和侧栏

简化顶部栏：隐藏语音搜索、虚拟键盘、搜索标签、上传按钮和通知。

把左侧栏精简到必需项，或者整体隐藏，包括“我”、历史记录、播放列表、稍后观看、
顶过的视频、订阅内容、探索、热门、音乐、直播、游戏、新闻、体育、Premium、
YouTube Music、Kids、Studio 以及页脚。

搜索结果也能清理：相关搜索、信息卡片和频道货架。

• 在深度工作时看教程的开发者和写作者

开源、轻量、注重隐私

YouTube Clean 完全开源，基于 Manifest V3 构建。

无账号、无跟踪、无分析、不收集数据。你的设置保存在浏览器本地。欢迎阅读代码、
反馈问题或在 GitHub 上提出功能需求。

常见问题

它能完全屏蔽 Shorts 吗？
可以。Shorts 能从首页、搜索、侧栏、频道页和左侧菜单中移除。你也可以保留 Shorts，
只关闭自动播放下一条。

它能去掉 YouTube 广告吗？
视频广告在可跳过时会被自动跳过，横幅广告、信息流赞助视频和推广面板会被隐藏。
它是 YouTube 清理工具，不是网络层面的广告拦截器。

YouTube 还能正常使用吗？
可以。所有功能默认关闭。在你打开开关之前什么都不会变，关闭后 YouTube 立即恢复
原样。

它会收集我的数据吗？
不会。没有账号、没有服务器、没有分析。设置保存在浏览器本地。

支持哪些浏览器？
Chrome 和 Opera，覆盖整个站点：首页、搜索、观看页、频道和播放器。

让 YouTube 适应你，而不是你去适应它。
