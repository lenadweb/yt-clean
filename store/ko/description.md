YouTube 쇼츠를 차단하고 추천을 정리해 영상에 집중하세요. YouTube Clean은 피드 필터, 댓글 숨기기, 실험적인 광고 건너뛰기와 재생 설정을 하나로 모은 무료 Chrome 확장 프로그램입니다. 원하는 동영상은 그대로 두고 주변의 불필요한 요소를 숨길 수 있습니다.

동영상 옆 측면 패널에서 70개 이상의 설정 중에서 선택하세요. 편집 가능한 사전 설정으로 시작하거나 홈 피드, 구독, 검색 결과, 보기 페이지, 플레이어 및 왼쪽 탐색 등 개별 요소를 맞춤설정하세요. 계정, 구독 또는 추적이 없는 무료 오픈 소스입니다.

기능 개요

• 짧은 비디오 선반과 탐색 항목을 제거합니다.
• 시청한 비디오, 믹스, 재생 목록 및 회원 전용 콘텐츠를 필터링합니다.
• 댓글, 실시간 채팅, 최종 화면 카드 및 홍보 패널을 숨깁니다.
• 컴팩트한 피드와 검색 레이아웃으로 썸네일을 더 작게 만드세요.
• 플레이어 내 속도 슬라이더를 사용하여 재생을 0.25x에서 3x까지 조정합니다.
• 키보드 단축키를 사용하여 정리 설정을 켜거나 끄십시오.

Shorts 섹션 숨기기

일반 동영상을 계속 사용할 수 있게 해주는 쇼츠 차단기를 찾고 계십니까? 피드에서 짧은 동영상 라이브러리를 숨기고, 일치하는 검색 결과를 제거하고, 왼쪽 메뉴에서 해당 항목을 지웁니다. 피드와 탐색 설정은 함께 작동하여 수직 스크롤에 대한 일반적인 진입점을 제거합니다.

미리 만들어진 정리 사전 설정을 사용하거나 관련 스위치를 개별적으로 활성화하십시오. 시청을 방해하는 짧은 형식의 콘텐츠를 제거하는 동시에 긴 형식의 비디오, 구독 및 검색을 계속 사용할 수 있습니다. 이러한 컨트롤은 인터페이스에 나타나는 내용을 변경합니다. 직접 비디오 링크는 계속 액세스할 수 있습니다.

비디오 피드에서 시청한 비디오 숨기기

이미 본 동영상을 스크롤하는 데 지치셨나요? 홈, 구독, 채널 페이지, 보기 페이지 추천에서 시청한 동영상을 독립적으로 제거하세요. 구독 피드에서는 필터를 켜 두고 다시 방문하고 싶은 채널에서는 끄거나 네 가지 설정을 모두 함께 사용하세요.

감지에서는 비디오 미리보기 이미지에 표시되는 시청 진행률 표시기를 사용합니다. 시청 기록을 삭제하거나 동영상을 시청한 것으로 표시하지 않고 표시되는 페이지를 필터링합니다. 일치하는 진행률 표시기가 없는 비디오는 계속 표시될 수 있습니다.

추천, 믹스, 재생목록 필터링

특정 종류의 콘텐츠를 필터링하여 유용한 제안을 위한 공간을 만드세요. 믹스와 재생목록을 숨기고, 회원 전용 동영상을 삭제하고, 탐색 또는 뉴스 차단을 해제하세요. 이러한 옵션을 시청한 비디오 필터와 결합하여 반복 제안을 줄이고 피드를 복잡하게 만듭니다.

이를 통해 검색을 유지하면서 표시되는 내용을 제어할 수 있습니다. 확장 프로그램은 선택한 콘텐츠 유형을 필터링합니다. 추천 알고리즘을 대체하거나 전체 홈 피드를 비우지 않습니다.

댓글, 실시간 채팅, 최종 화면 카드 숨기기

주의를 끌기 위해 경쟁하는 아래 토론 없이 강의를 시청하세요. 비디오 페이지에서 댓글을 숨기고, 스트리밍 중에 실시간 채팅을 제거하고, 최종 화면 카드나 플레이어 위에 있는 카드 티저를 지웁니다.

또한 상품 및 티켓 선반, 좋아요 및 싫어요 컨트롤, 작업 버튼, 채널 사진을 제거할 수도 있습니다. 각 설정은 독립적이므로 깔끔한 보기 페이지에서는 설명, 캡션 버튼 또는 사용하는 기타 요소를 계속 유지할 수 있습니다.

광고 건너뛰기 및 스폰서 동영상 숨기기

배너, 후원 비디오 카드 및 광고 정보 패널을 숨겨 광고를 깔끔하게 정리하세요. 이러한 제어 기능은 별도로 작동하므로 탐색 페이지와 보기 페이지에서 어떤 프로모션 요소가 사라지도록 선택할 수 있습니다.

선택적 광고 선장은 동영상 광고를 자동으로 건너뛰려고 시도합니다. 자동 건너뛰기는 실험적입니다. 동작은 현재 플레이어와 광고 형식에 따라 다릅니다. 자동 광고 건너뛰기를 시도하려면 별도로 활성화하세요. 네트워크 수준의 광고 차단기가 아니며 광고 없는 환경을 보장하지 않습니다.

마우스오버 자동 미리보기 끄기

포인터가 비디오 위로 지나갈 때 시작되는 썸네일 미리보기 이동을 중지합니다. 미리보기를 꺼서 더 조용하고 정적인 피드를 탐색하고 미리보기가 주의를 끌지 않고도 제목을 읽을 수 있습니다.

이 설정은 축소판 동작을 제어합니다. 자동 재생 스위치를 숨기는 별도의 옵션은 플레이어에서 해당 버튼만 제거합니다. 다음 비디오 자동 재생을 비활성화하지 않습니다.

더 작은 비디오 썸네일과 간결한 레이아웃

너무 큰 썸네일 대신 화면당 더 많은 동영상을 원하시나요? 컴팩트 모드는 홈 피드, 검색 결과, 보기 페이지 제안의 시각적 부피를 줄입니다. 더 작은 미리 보기, 더 좁은 간격 및 더 조밀한 배열을 통해 제목을 스캔하고 결과를 비교하기가 더 쉬워졌습니다.

컴팩트 그리드를 사용하여 튜토리얼을 찾아보고, 시리즈의 다음 에피소드를 찾거나, 스크롤을 덜 하면서 검색 결과를 살펴보세요. 레이아웃은 사전 설정된 배열이므로 CSS를 편집하거나 개별 열 너비를 구성할 필요가 없습니다.

재생 속도 슬라이더

비디오 플레이어 내에서 직접 재생 속도를 조정하세요. 0.25x에서 3x까지 슬라이더를 사용하거나, 0.05x 단계로 미세 조정하거나, 1.25x, 1.5x, 2x 또는 3x와 같은 사전 설정을 선택하세요. 선택한 속도는 확장 설정에 저장됩니다.

언어 연습 중에는 발음을 늦추고, 자신의 속도에 맞춰 자세한 시연을 따라가거나, 친숙한 강의 속도를 높이세요. 속도 컨트롤러는 일반 보기 페이지 동영상에 사용할 수 있습니다. 더 간단한 플레이어 컨트롤 세트를 위해 미니 플레이어, 극장 또는 자막 버튼을 숨길 수도 있습니다.

H.264, VP9, AV1, 60 fps, Enhanced Bitrate

고급 재생 제어 기능을 사용하면 VP9 및 AV1을 차단하여 H.264를 강제로 적용하거나 낮은 프레임 속도의 비디오를 선호하는 경우 60fps 스트림을 차단할 수 있습니다. 이는 코덱 지원이 제한된 구형 노트북 및 장치에 유용할 수 있습니다. 하드웨어 디코딩, CPU 로드 및 사용 가능한 품질은 장치와 각 비디오에 제공되는 스트림에 따라 다릅니다. H.264를 강제하면 사용 가능한 해상도가 제한될 수 있습니다.

프리미엄 가입자는 해당 옵션을 사용할 수 있는 경우 향상된 비트 전송률을 선호할 수 있습니다. 이 설정은 기존 재생 옵션을 선택하며 유료 기능을 잠금 해제하지 않습니다. 추가 실험 설정은 플레이어가 사용하는 대역폭 추정치를 조정합니다. 실제 연결 속도는 변경되지 않습니다.

사이드바를 숨기고 탐색을 단순화하세요

왼쪽 탐색 사이드바를 완전히 제거하거나 개별 메뉴 항목을 자릅니다. 기록, 재생 목록, 나중에 볼 동영상, 좋아요 표시한 동영상, 다운로드, 구독, 인기 급상승, 음악, 게임, 뉴스 및 기타 섹션 중에서 계속 표시할 내용을 선택하세요. 콘텐츠 탐색을 덜 원할 경우 바닥글 링크를 지웁니다.

상단 표시줄도 단순화합니다. 알림, 업로드 버튼, 음성 검색, 가상 키보드 버튼 또는 검색 태그를 숨깁니다. 이는 가시성 설정입니다. 재생 목록, 구독 또는 계정 콘텐츠는 삭제되지 않습니다.

검색 결과 및 채널 페이지 정리

채널 결과 카드, 관련 검색 제안, 정보 카드 또는 채널 비디오 라이브러리를 숨겨 검색 결과를 더 쉽게 검색할 수 있습니다. 더 조밀한 결과 페이지를 원할 경우 해당 컨트롤을 컴팩트 모드와 결합하세요.

채널 페이지에서 배너와 채널 예고편을 숨깁니다. 큰 장식 요소가 적고 추천 예고편의 방해가 적은 동영상을 찾아보세요.

표시할 동영상 설명 섹션을 선택하세요.

전체 설명을 숨기거나 개별 섹션을 선택하세요. 옵션에는 AI 요약, 대본, 언급된 사람, 관련 비디오, 채널 카드, "이것이 어떻게 만들어졌는지", 장 또는 에피소드가 포함됩니다.

학습을 위해 스크립트와 장을 표시하거나 더 짧은 설명을 원할 경우 제거하세요. 이러한 컨트롤은 기존 페이지 섹션을 숨깁니다. 요약을 생성하거나, 성적표를 다시 작성하거나, 작성자의 콘텐츠를 변경하지 않습니다.

공부와 집중 작업을 위한 방해 없는 YouTube

사이트 사용 방식에 초점을 맞춘 보기 설정을 구축하세요.

• 학생: 수업을 보거나 시험을 준비하는 동안 사료가 어지러워지는 것을 줄입니다.
• 개발자 및 연구원: 심층 작업 중에 튜토리얼과 데모를 쉽게 이용할 수 있습니다.
• 언어 학습자: 더 조용한 페이지와 정확한 속도 조정을 결합합니다.
• 일반 시청자: 구독을 통해 탐색하기가 더 쉬워지고 반복 제안이 줄어듭니다.
• 디지털 미니멀리스트: 시각적 잡음을 제거하고 의도적인 시청을 디지털 디톡스 루틴의 일부로 만듭니다.

더 작은 정리를 위해서는 가볍게를 선택하고 더 광범위한 필터 세트를 위해서는 균형를 선택하세요. 두 사전 설정 모두 편집하고 재설정할 수 있습니다. 사용자 지정는 정리 스위치가 꺼진 상태로 시작하여 사용자가 직접 구성을 구축할 수 있습니다. 균형 사전 설정은 설치 시 기본적으로 선택됩니다.

필요에 따라 개별 설정을 전환하거나 확장 프로그램의 키보드 단축키를 사용하여 전체 구성을 켜거나 끌 수 있습니다. 필수 집중 타이머, 사용 할당량 또는 잠긴 학습 세션이 없습니다.

로컬 설정이 포함된 무료 오픈 소스

모든 확장 설정은 결제나 등록 없이 이용 가능합니다. 구독, 평가판 카운트다운 또는 자동 사용량 추적이 없습니다. 기본 설정은 브라우저에 로컬로 저장됩니다. 피드백 보내기를 선택하면 메시지와 확장 버전이 PostHog를 통해 개발자에게 전송됩니다. 검색 기록이나 계정 세부 정보가 첨부되지 않습니다. 전체 소스 코드는 MIT 라이선스에 따라 GitHub에서 사용할 수 있습니다.

52개 언어로 제공되는 인터페이스를 갖춘 Chrome의 데스크톱 웹사이트용으로 설계되었습니다. 모바일 앱은 수정되지 않습니다. 대부분의 인터페이스 정리는 CSS를 사용합니다. 재생 및 기타 대화형 기능은 로컬 JavaScript를 사용합니다.

3단계로 시작하세요

1. 크롬에 YouTube Clean를 추가하고 웹사이트를 엽니다.
2. 확장 아이콘을 클릭하여 측면 패널을 엽니다.
3. 사전 설정을 선택한 다음 원하는 피드, 탐색 및 재생 설정을 조정합니다.

인터페이스 가시성 변경 사항은 전환할 때 적용됩니다. 컨트롤에 쉽게 접근할 수 있도록 확장 프로그램을 도구 모음에 고정하세요. 페이지 요소가 변경되고 필터가 해당 요소와 일치하지 않는 경우 확인할 수 있도록 문제를 보고하세요.
