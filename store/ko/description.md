YouTube Shorts를 차단하고, 추천을 숨기고, 광고를 건너뛰고, 주의를 빼앗는 나머지
요소를 모두 제거하세요. YouTube Clean은 YouTube를 여러분이 직접 제어하는 조용하고
방해 없는 공간으로 바꿔줍니다.

60개 이상의 설정, 하나의 사이드 패널, 즉각 적용. 무료, 오픈소스, 계정 불필요,
추적 없음, 데이터 수집 없음.

숨기거나 차단할 수 있는 항목

• Shorts: 홈 피드, 검색 결과, 사이드바, 채널 페이지, 왼쪽 메뉴 항목
• 추천: 홈 피드, 동영상 페이지 옆 열, 최종 화면 카드
• 광고: 동영상 광고 자동 건너뛰기, 배너, 피드의 스폰서 동영상
• 댓글 및 실시간 채팅
• 믹스, 재생목록, 인기 급상승, 탐색, 뉴스
• 상품 및 티켓 선반, 채널 배너와 예고편
• 마우스오버 자동 미리보기, 지나치게 긴 동영상 설명
• 사이드바: 전체 숨기기 또는 항목별 숨기기
• 상단바: 음성 검색, 가상 키보드, 검색 태그, 업로드, 알림
• 검색 결과: 관련 검색어, 정보 카드, 채널 선반

YOUTUBE SHORTS와 끝없는 스크롤 차단

짧은 동영상은 YouTube에서 가장 강력한 주의 함정입니다.

YouTube Clean은 홈 피드, 검색 결과, 사이드바, 채널 페이지에서 Shorts를 제거해
잠깐의 방문이 한 시간의 스크롤로 이어지지 않게 합니다.

Shorts를 남겨두고 싶다면 Shorts 전용 속도 조절을 사용하고 자동 넘김을 끄세요.
그러면 Shorts 하나는 끝없는 피드가 아니라 그냥 하나로 끝납니다.

추천과 피드의 잡음 숨기기

무엇을 남기고 무엇을 없앨지는 여러분이 정합니다.

추천 동영상, 믹스와 재생목록, 댓글, 실시간 채팅, 최종 화면 카드, 상품과 티켓
선반, 알림, 인기 급상승 섹션을 숨기세요.

시각적 잡음을 더 줄이세요. 마우스오버 미리보기를 끄고, 채널 배너와 예고편을
숨기고, 설명은 실제로 읽는 내용만 남기세요.

광고와 스폰서 콘텐츠 건너뛰기

동영상 광고는 건너뛰기 버튼이 나타나는 즉시 자동으로 건너뜁니다.

광고 배너, 피드의 스폰서 동영상, 프로모션 정보 패널은 피드와 시청 페이지 모두에서
숨겨져 탐색이 끊기지 않습니다.

집중과 학습을 위한 방해 없는 YOUTUBE

YouTube Clean은 공격적인 차단기가 아니라 부드러운 집중 도구입니다.

여러분이 요청하기 전까지는 아무것도 제거되지 않으며, 차분한 사이드 패널이 모든
설정을 한 번의 클릭 거리에 둡니다. 계정도, 대시보드도, 잔소리 알림도 없습니다.

많은 사람이 이를 YouTube용 가벼운 디지털 디톡스 도구로 사용합니다. 금지가 아니라
통제가 핵심입니다.

원클릭 프리셋: 가볍게, 균형, 사용자 지정

준비된 프리셋으로 시작하세요. 가벼운 정리에는 Light, 집중 모드에는 Balanced,
또는 설정을 하나씩 골라 나만의 Custom 프로필을 만드세요.

일과 휴식을 오갈 때 프리셋을 바꾸세요. 필요할 때는 도구가 되고, 필요 없을 때는
물러납니다.

간결한 레이아웃: 한 화면에 더 많은 동영상

간단히 보기 모드는 홈 피드, 검색 결과, 시청 페이지 추천을 깔끔한 목록이나
그리드로 바꿉니다.

스크롤은 줄고, 화면당 결과는 늘고, 큰 모니터를 마침내 제대로 활용하는 레이아웃이
됩니다.

재생 속도 슬라이더와 깔끔한 플레이어

플레이어 안의 슬라이더로 재생 속도를 세밀하게 조절하세요. Shorts용 별도 속도
조절도 있습니다.

미니 플레이어, 극장 모드, 자막 버튼을 숨겨 플레이어를 정리하고, 자동재생 스위치를
꺼서 다음 동영상이 저절로 시작되지 않게 하세요.

깔끔한 검색, 상단바, 사이드바

음성 검색, 가상 키보드, 검색 태그, 업로드 버튼, 알림을 숨겨 상단바를
단순화하세요.

왼쪽 사이드바를 꼭 필요한 항목만 남기거나 통째로 숨기세요. 나, 시청 기록,
재생목록, 나중에 볼 동영상, 좋아요 표시한 동영상, 구독, 탐색, 인기 급상승, 음악,
실시간, 게임, 뉴스, 스포츠, Premium, YouTube Music, Kids, 스튜디오, 푸터가
포함됩니다.

검색 결과도 정리할 수 있습니다. 관련 검색어, 정보 카드, 채널 선반.

YOUTUBE CLEAN은 누구에게 좋은가

• Shorts가 아니라 강의를 위해 YouTube가 필요한 학생과 연구자
• 깊은 작업 중에 튜토리얼을 보는 개발자와 작가
• 긴 영상에서 속도 슬라이더를 쓰는 언어 학습자
• 공용 컴퓨터에서 더 차분한 YouTube를 원하는 부모
• 디지털 디톡스 중이지만 업무에는 여전히 YouTube가 필요한 모든 사람

오픈소스, 가볍고 프라이빗

YouTube Clean은 완전한 오픈소스이며 Manifest V3 기반으로 만들어졌습니다.

계정 없음, 추적 없음, 분석 없음, 데이터 수집 없음. 설정은 브라우저에 남습니다.
코드를 읽고, 문제를 제보하고, GitHub에서 기능을 요청하세요.

자주 묻는 질문

Shorts를 완전히 차단하나요?
네. Shorts는 홈 피드, 검색, 사이드바, 채널 페이지, 왼쪽 메뉴에서 제거할 수
있습니다. Shorts를 남기고 자동 넘김만 끌 수도 있습니다.

YouTube 광고를 제거하나요?
동영상 광고는 건너뛸 수 있게 되는 즉시 자동으로 건너뛰며, 배너, 피드의 스폰서
동영상, 프로모션 패널은 숨겨집니다. 네트워크 수준의 광고 차단기가 아니라 YouTube
정리 도구입니다.

YouTube의 나머지 기능은 정상 작동하나요?
네. 모든 기능은 기본적으로 꺼져 있습니다. 설정을 켜기 전까지는 아무것도 바뀌지
않으며, 끄면 YouTube가 즉시 원래대로 돌아옵니다.

데이터를 수집하나요?
아니요. 계정도, 서버도, 분석도 없습니다. 설정은 브라우저에 로컬로 저장됩니다.

어떤 브라우저를 지원하나요?
Chrome과 Opera. 홈 피드, 검색, 시청 페이지, 채널, 플레이어까지 사이트 전체에서
작동합니다.

YouTube가 여러분에게 맞춰집니다. 그 반대가 아니라.
