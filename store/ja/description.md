YouTube Clean は Shorts、おすすめ、コメント、広告を非表示にします。ページに残るのは、あなたが観に来た動画だけです。

YouTube はスクロールを止めさせない作りになっています。終わらない Shorts の棚、プレーヤー横に積み上がるおすすめ、カーソルが触れただけで再生されるプレビュー、「1本だけ」を1時間に変えるサムネイル。YouTube Clean はその場所をあなたに返します。サイドパネルを開いてスイッチを入れるだけで、余計なものはその場で消えます。ページの再読み込みも、アカウントも、初期設定も不要です。

60以上のスイッチ、サイドパネル1枚、切り替えた瞬間に反映。無料、オープンソース、トラッキングなし。

片づけられるもの

フィードとおすすめ。Shorts の棚をあらゆる場所で非表示にし、ミックスと再生リスト、「探索」と「ニュース」のブロック、メンバー限定動画も隠せます。カーソルを重ねたときの自動プレビューをオフにし、コンパクトモードで画面に入る動画を増やし、視聴済みの動画を非表示に。ホーム、登録チャンネル、チャンネルページ、おすすめのそれぞれで個別に設定できます。

動画ページ。コメント、プレーヤー横のおすすめ動画、高評価・低評価、アクションボタン、概要欄、ライブチャット、グッズとチケット、終了画面のカード、チャンネル画像を非表示にできます。概要欄はさらに細かく分解でき、AI セクション（Gemini）、文字起こし、言及された人物、関連動画、チャンネルカード、「この動画の作り方」、チャプターとエピソードを個別に消せます。

広告とプロモーション。YouTube のバナー、フィード内のスポンサー動画、広告の情報パネルを非表示に。実験的な自動スキップを有効にすれば、スキップ可能な広告は勝手に片づきます。

プレーヤーと再生。再生速度スライダーをプレーヤーの操作バーに直接追加。Premium では高ビットレートを優先し、H.264 コーデックを強制（VP9 と AV1 をブロック）して CPU を熱くする代わりに GPU にデコードさせ、非力なマシンでは 30 fps に制限できます。ミニプレーヤー、シアターモード、字幕、自動再生の各ボタンも隠せます。

Shorts。Shorts を残すなら自分のルールで。専用の速度コントロールと、次の Short への自動切り替えがあります。

サイドバーとナビゲーション。サイドバーをまるごと非表示にするか、項目ごとに削れます。Shorts、マイチャンネル、履歴、再生リスト、自分の動画、後で見る、高く評価した動画、映画、ダウンロード、登録チャンネル一覧すべて、急上昇、音楽、ライブ、ゲーム、ニュース、スポーツ、YouTube Premium / Music / Kids / Studio のリンク、概要リンクを含むフッター。

検索とチャンネル。検索結果内のチャンネル、関連する検索、検索の情報カード、チャンネルの動画棚を非表示に。チャンネルページではバナーと自動再生されるトレーラーを取り除けます。

ヘッダー。音声検索と仮想キーボードのボタン、検索タグ、アップロードボタン、通知を非表示にできます。

何も設定したくない人のためのプリセット

軽く片づけるなら「ライト」、日常使いの集中できる YouTube なら「バランス」、ほぼ全部そぎ落とすなら「最大」。どのプリセットも編集でき、いつでも初期状態に戻せます。「カスタム」はゼロから自分で組み立てる枠です。キーボードショートカットで拡張機能全体をオン・オフできるので、元の YouTube を少しだけ見たいときにも困りません。

プライバシーについて、はっきりと

アカウント不要、ログイン不要、アナリティクスなし、トラッキングなし、データ収集なし。設定はブラウザのローカルストレージに保存され、外に出ることはありません。ソースコードは MIT ライセンスで GitHub に公開されているので、言葉を信じる必要はありません。

速さを落とさない設計

ほとんどの機能はビルド時に純粋な CSS へコンパイルされるため、閲覧中のコストはゼロです。JavaScript を動かすのは、動作を伴うごく一部の機能だけ。Manifest V3、リモートコードなし、バックグラウンドの負荷なし。

はじめかた

拡張機能をインストールし、アイコンをクリックして YouTube の横にサイドパネルを開き、プリセットを選ぶか個別のスイッチを切り替えます。変更は開いているページにその場で反映されます。

Chrome、Opera、Edge、Brave など Chromium ベースのブラウザで動作します。

よくある質問

広告ブロッカーですか？　厳密には違います。バナー、フィード内のスポンサーカード、広告情報パネルを非表示にし、スキップ可能な広告を自動でスキップできます（実験的）。専用の広告ブロッカーと併用しても問題ありません。

YouTube が壊れませんか？　すべて任意で、元に戻せます。スイッチを切れば要素はすぐ戻ります。

アカウントは必要ですか？　不要です。入れてすぐ使えます。

本当に無料ですか？　はい。無料かつオープンソースで、有料プランもアップセルもありません。

思ったとおりに隠れないものがありますか？　GitHub で issue を立ててください。機能はユーザーの要望から増えています。
