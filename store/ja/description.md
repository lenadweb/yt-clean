# YouTube Clean — ショート非表示・おすすめ削除・集中＆デトックス

YouTube を、静かで、すっきりして、集中しやすい場所に。

YouTube Clean は YouTube を、自分でちゃんとコントロールできる落ち着いた空間に変えます。

注意を奪うもの——ショート動画、おすすめ、広告、コメント、UI の雑多な要素——を取り除くので、
見たかったものだけを見て、そのまま離れられます。

YouTube Clean には 60 以上の設定があり、YouTube の見た目と動きを細かくカスタマイズできます。
フィードのレイアウト、コンテンツの整理、プレーヤーの操作、再生速度、集中用プリセットまで。
すべて任意で、切り替えは即座に反映され、同じ速さで元に戻せます。

🧩 ショート動画と無限スクロールを制御

短い動画は、いちばん強力な「注意のわな」のひとつです。

YouTube Clean は、ホームフィード、検索結果、サイドバー、チャンネルページからショートを非表示にします。
「ちょっと見るだけ」が 1 時間のスクロールに変わることを防ぎます。

残しておきたい場合は、ショート専用の速度コントロールを使い、自動送りをオフに。
1 本のショートが 1 本のままで終わります。

🧹 すっきりした YouTube、少ないノイズ

何を残して何を消すかは、あなたが決めます。

気が散るなら、おすすめ、ミックスと再生リスト、コメント、ライブチャット、終了画面のカード、
グッズ・チケット枠、通知、急上昇セクションを削除できます。

視覚的なノイズも軽減。マウスオーバー時の自動プレビューをオフにし、チャンネルのバナーや
トレーラーを隠し、説明欄を本当に読む部分だけに絞り込めます。

🚫 広告を減らし、中断を減らす

動画広告は、スキップ可能になった時点で自動的にスキップされます。

広告バナー、フィード内のスポンサー動画、プロモーション情報パネルは、フィードと視聴ページから
非表示になり、閲覧が途切れません。

🧠 穏やかに集中できる体験

YouTube Clean は攻撃的なブロッカーではなく、やさしい集中ツールです。

あなたが求めるまで何も削除されません。落ち着いたサイドパネルから、すべての設定が 1 クリックで。
アカウント登録も、複雑なダッシュボードも、しつこい通知もありません。

YouTube 向けの軽量なデジタルデトックスツールとして使う人も多くいます。
制限ではなく、コントロールのためのツールです。

⏱ 生産性と、意図的な視聴

すぐ使えるプリセットから始められます。軽く整える「Light」、集中向けの「Balanced」、
または自分専用のカスタム設定を 1 項目ずつ組み立てることもできます。

仕事と休憩でプリセットを切り替えれば、必要なときは道具として、必要ないときは邪魔をしない
YouTube になります。

📐 画面を活かすコンパクトレイアウト

コンパクトモードは、ホームフィード、検索結果、視聴ページのおすすめを、整ったリストまたは
グリッド表示に変えます。

スクロールは減り、1 画面あたりの情報量は増え、大きなモニターをようやく活かせます。

🎥 プレーヤーと再生をより快適に

プレーヤー内の速度スライダーで、再生を細かく調整できます。

ミニプレーヤー、シアターモード、字幕のボタンを隠して操作部を整理し、自動再生スイッチをオフに
すれば、次の動画が勝手に始まることはありません。

🔎 検索・ヘッダー・サイドバーの整理

音声検索、仮想キーボード、検索タグ、アップロードボタン、通知を非表示にして、上部バーを
シンプルにできます。

左サイドバーは必要な項目だけに——または完全に非表示に。あなた、履歴、再生リスト、後で見る、
高く評価した動画、登録チャンネル、探索、急上昇、Music、ライブ、ゲーム、ニュース、スポーツ、
Premium、YouTube Music、Kids、Studio、フッターまで対応します。

検索結果も整理できます。関連する検索、情報カード、チャンネル枠など。

🔓 オープンソース・軽量・プライバシー重視

YouTube Clean は完全にオープンソースです。

アカウント不要、トラッキングなし、データ収集なし。設定はブラウザー内にとどまります。
コードの確認、不具合の報告、機能のリクエストは GitHub から。

🌍 見る場所すべてで動作

YouTube Clean は Chrome と Opera で動作し、ホームフィード、検索、視聴ページ、チャンネル、
プレーヤーまでサイト全体に効きます。

YouTube があなたに合わせる——その逆ではなく。

勉強、集中作業、リサーチ、語学学習、講義、チュートリアル、長尺動画の視聴に最適です。
