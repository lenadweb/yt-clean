# YouTube Clean: ショートをブロック、おすすめ・広告を非表示

YouTube ショートをブロックし、おすすめを非表示にし、広告をスキップして、集中を
奪うものをまとめて取り除きます。YouTube Clean は YouTube を、自分で操れる静かで
気が散らない場所に変えます。

60以上の設定、サイドパネル1つ、効果は即時。無料、オープンソース、アカウント不要、
トラッキングなし、データ収集なし。

非表示・ブロックできるもの

・ショート: ホーム、検索結果、サイドバー、チャンネルページ、メニュー項目
・おすすめ: ホーム、動画ページの横の列、終了画面カード
・広告: 動画広告の自動スキップ、バナー、フィードの広告動画
・コメントとライブチャット
・ミックス、再生リスト、急上昇、探索、ニュース
・グッズとチケットの棚、チャンネルバナーと予告編
・ホバー時の自動プレビュー、長すぎる動画概要
・サイドバー: 丸ごと、または項目ごとに非表示
・ヘッダー: 音声検索、仮想キーボード、検索タグ、アップロード、通知
・検索結果: 関連検索、情報カード、チャンネルの棚

YOUTUBE ショートと無限スクロールをブロック

短尺動画は YouTube で最大の注意の罠です。

YouTube Clean はホーム、検索結果、サイドバー、チャンネルページからショートを
取り除くので、「ちょっと見るだけ」が1時間のスクロールになりません。

ショートは残したい場合は、ショート専用の速度コントロールを使い、自動送りをオフに
してください。1本のショートが1本のままで終わり、無限フィードになりません。

おすすめとフィードの雑音を非表示

何を残して何を消すかは、あなたが決めます。

おすすめ動画、ミックスと再生リスト、コメント、ライブチャット、終了画面カード、
グッズとチケットの棚、通知、急上昇セクションを非表示にできます。

視覚的な雑音をさらに削減: ホバー時の自動プレビューをオフにし、チャンネルバナーと
予告編を隠し、概要欄を本当に読む部分だけに絞り込めます。

広告とスポンサーコンテンツをスキップ

動画広告は、スキップボタンが出た瞬間に自動でスキップされます。

広告バナー、フィード内のスポンサー動画、プロモ情報パネルはフィードでも視聴ページ
でも非表示になり、閲覧が途切れません。

集中と学習のための気が散らない YOUTUBE

YouTube Clean は攻撃的なブロッカーではなく、穏やかな集中ツールです。

あなたが求めるまで何も消えません。落ち着いたサイドパネルがすべての設定を1クリック
の距離に保ちます。アカウント不要、ダッシュボード不要、しつこい通知もなし。

多くの人が YouTube 用の軽いデジタルデトックスツールとして使っています。禁止では
なくコントロールが軸です。

ワンクリックのプリセット: ライト、バランス、カスタム

用意されたプリセットから始められます。軽い整理なら Light、集中モードなら
Balanced、あるいは自分の Custom プロファイルを1つずつ組み立てられます。

仕事と休憩の切り替えでプリセットを変えれば、必要なときは道具になり、そうでない
ときは邪魔をしません。

コンパクト表示: 1画面により多くの動画

コンパクトモードは、ホーム、検索結果、視聴ページのおすすめを、すっきりしたリスト
またはグリッドに変えます。

スクロールは減り、1画面あたりの表示は増え、大きなモニターをようやく活かせる
レイアウトになります。

再生速度スライダーとすっきりしたプレーヤー

プレーヤー内のスライダーで再生速度を細かく調整できます。ショート用の速度コント
ロールも別に用意されています。

ミニプレーヤー、シアター、字幕のボタンを隠してプレーヤーを整理し、自動再生スイッチ
をオフにすれば、次の動画が勝手に始まることはありません。

検索・ヘッダー・サイドバーを整理

上部バーを簡素化: 音声検索、仮想キーボード、検索タグ、アップロードボタン、通知を
非表示にできます。

左サイドバーは必要な項目だけに絞るか、丸ごと非表示にできます。マイページ、履歴、
再生リスト、後で見る、高く評価した動画、登録チャンネル、探索、急上昇、音楽、
ライブ、ゲーム、ニュース、スポーツ、Premium、YouTube Music、Kids、Studio、
フッターが対象です。

検索結果も整理できます: 関連検索、情報カード、チャンネルの棚。

YOUTUBE CLEAN が向いている人

・ショートではなく講義のために YouTube を使う学生や研究者
・深い集中作業中にチュートリアルを見る開発者や書き手
・長尺動画で速度スライダーを使う語学学習者
・共有パソコンで静かな YouTube を望む保護者
・デジタルデトックス中でも仕事に YouTube が必要な人

オープンソース、軽量、プライバシー重視

YouTube Clean は完全なオープンソースで、Manifest V3 で作られています。

アカウントなし、トラッキングなし、解析なし、データ収集なし。設定はブラウザー内に
残ります。コードを読み、問題を報告し、GitHub で機能を提案できます。

よくある質問

ショートを完全にブロックできますか?
はい。ホーム、検索、サイドバー、チャンネルページ、左メニューからショートを除去
できます。ショートを残して自動送りだけをオフにすることもできます。

YouTube の広告を消せますか?
動画広告はスキップ可能になった瞬間に自動スキップされ、バナー、フィードのスポン
サー動画、プロモパネルは非表示になります。ネットワークレベルの広告ブロッカーでは
なく、YouTube の整理ツールです。

YouTube はこれまで通り使えますか?
はい。すべての機能は初期状態でオフです。スイッチを入れるまで何も変わらず、オフに
すればすぐ元の YouTube に戻ります。

データを収集しますか?
いいえ。アカウントもサーバーも解析もありません。設定はブラウザーにローカル保存
されます。

対応ブラウザーは?
Chrome と Opera。ホーム、検索、視聴ページ、チャンネル、プレーヤーまでサイト全体
で動作します。

YouTube があなたに合わせます。その逆ではありません。
