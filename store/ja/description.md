YouTubeのショートをブロックし、おすすめを整理して、動画の視聴に集中しましょう。YouTube Cleanは、フィードの絞り込み、コメントの非表示、実験的な広告スキップ、再生設定をまとめた無料のChrome拡張機能です。見たい動画は残し、周囲の不要な要素を非表示にできます。

ビデオの横にあるサイドパネルで 70 以上の設定から選択します。編集可能なプリセットから始めるか、ホーム フィード、登録、検索結果、再生ページ、プレーヤー、左側のナビゲーションなどの個々の要素をカスタマイズします。無料のオープンソースで、アカウント、サブスクリプション、追跡はありません。

主な機能

• ショートビデオの棚とそのナビゲーション エントリを削除します。
• 視聴したビデオ、ミックス、プレイリスト、メンバー限定コンテンツをフィルターで除外します。
• コメント、ライブチャット、終了画面カード、プロモーションパネルを非表示にします。
• コンパクトなフィードと検索のレイアウトにより、サムネイルを小さくします。
• プレーヤー内の速度スライダーを使用して、再生を 0.25 倍から 3 倍まで調整します。
• キーボード ショートカットを使用して、クリーンアップ設定のオンとオフを切り替えます。

ショート動画セクションを非表示

通常の動画を引き続き使用できるようにする ショート ブロッカーをお探しですか?フィード内のショートビデオの棚を非表示にし、一致する検索結果を削除して、左側のメニューからエントリをクリアします。フィードとナビゲーションの設定は連携して、垂直スクロールへの共通のエントリ ポイントを削除します。

既製のクリーンアップ プリセットを使用するか、関連するスイッチを個別に有効にします。視聴を中断する短い形式のコンテンツを削除しながら、長い形式のビデオ、サブスクリプション、および検索を利用可能な状態に保つことができます。これらのコントロールは、インターフェイスに表示される内容を変更します。ビデオの直接リンクは引き続きアクセス可能です。

視聴済み動画をフィードから非表示にする

すでに見た過去のビデオをスクロールすることにうんざりしていませんか?視聴した動画をホーム、定期購読、チャンネル ページ、再生ページのおすすめから個別に削除します。購読フィードではフィルターをオンにし、再訪問したいチャンネルではフィルターをオフにするか、4 つの設定をすべて一緒に使用します。

検出には、ビデオのサムネイルに表示される視聴進行状況インジケーターが使用されます。再生履歴を削除したり、ビデオを再生済みとしてマークしたりせずに、表示されているページをフィルタリングします。一致する進行状況インジケーターのないビデオは表示されたままになる場合があります。

おすすめ、ミックス、プレイリストをフィルターする

特定の種類のコンテンツをフィルタリングして、有用な提案が入る余地を作ります。ミックスとプレイリストを非表示にし、メンバー限定のビデオを削除し、Explore または News ブロックをクリアします。これらのオプションを視聴済みビデオ フィルターと組み合わせて、繰り返しの提案やフィードの乱雑さを軽減します。

これにより、発見を維持しながら、表示されたままにするものを制御できます。拡張機能は、選択されたコンテンツ タイプをフィルタリングします。レコメンデーションアルゴリズムを置き換えたり、ホームフィード全体を空白にしたりするものではありません。

コメント、ライブチャット、終了画面カードを非表示にする

講義の下にある議論が注目を集めることなく視聴してください。ビデオ ページのコメントを非表示にし、ストリーム中のライブ チャットを削除し、プレーヤー上の終了画面カードやカード ティーザーを消去します。

商品やチケットの棚、好き嫌いのコントロール、アクション ボタン、チャンネルの写真を削除することもできます。各設定は独立しているため、よりクリーンな動画再生ページでは、説明、キャプション ボタン、または使用するその他の要素を維持できます。

広告をスキップし、スポンサー動画を非表示にする

バナー、スポンサー付きビデオ カード、広告情報パネルを非表示にして、煩雑な広告をすっきりさせます。これらのコントロールは個別に機能するため、閲覧ページや表示ページからどのプロモーション要素を非表示にするかを選択できます。

オプションの広告スキッパーは、動画広告を自動的にスキップしようとします。自動スキップは実験的なものです。その動作は現在のプレーヤーと広告形式によって異なります。自動広告スキップを試したい場合は別途有効にしてください。これはネットワーク レベルの広告ブロッカーではなく、広告なしのエクスペリエンスを保証するものではありません。

ホバー時の自動プレビューを無効化

ポインタがビデオ上を通過したときにサムネイルのプレビューの移動が開始されないようにします。ホバー プレビューをオフにすると、静かで静的なフィードを閲覧し、プレビューがユーザーの注意を引くことなくタイトルを読むことができます。

この設定は、サムネイルの動作を制御します。自動再生スイッチを非表示にする別のオプションは、そのボタンをプレーヤーから削除するだけです。次のビデオの自動再生は無効になりません。

サムネイルを小さくして一覧をコンパクトに

特大のサムネイルではなく、1 画面あたりのビデオ数を増やしたいですか?コンパクト モードでは、ホーム フィード、検索結果、動画再生ページの候補の視覚的なボリュームが軽減されます。プレビューが小さく、間隔が狭く、配置が密になっているため、タイトルをスキャンして結果を比較することが簡単になります。

コンパクトなグリッドを使用して、チュートリアルを参照したり、シリーズの次のエピソードを見つけたり、少ないスクロールで検索結果を確認したりできます。レイアウトはプリセットされた配置であるため、CSS を編集したり、個々の列幅を設定したりする必要はありません。

再生速度調整スライダー

ビデオプレーヤー内で再生速度を直接調整します。 0.25x から 3x までのスライダーを使用するか、0.05x ステップで微調整するか、1.25x、1.5x、2x、3x などのプリセットを選択します。選択した速度は拡張機能の設定に保存されます。

言語の練習中に発音を遅くしたり、自分のペースで詳細なデモンストレーションに従ったり、馴染みのある講義の速度を上げたりできます。スピード コントローラーは通常の動画再生ページで使用できます。ミニプレーヤー、シアター、または字幕ボタンを非表示にして、プレーヤー コントロールのセットをよりシンプルにすることもできます。

H.264, VP9, AV1, 60 fps, Enhanced Bitrate

高度な再生コントロールを使用すると、VP9 と AV1 をブロックして H.264 を強制したり、低フレーム レートのビデオを好む場合は 60 fps ストリームをブロックしたりできます。これは、コーデックのサポートが制限されている古いラップトップやデバイスで便利です。ハードウェア デコード、CPU 負荷、利用可能な品質は、デバイスと各ビデオに提供されるストリームによって異なります。 H.264 を強制すると、利用可能な解像度が制限される可能性があります。

プレミアム加入者は、拡張ビットレートのオプションが利用可能な場合、それを優先できます。この設定では既存の再生オプションが選択され、有料機能のロックは解除されません。追加の実験的な設定により、プレーヤーが使用する帯域幅の推定値が調整されます。実際の接続速度は変わりません。

サイドバーを非表示にしてナビゲーションを簡素化する

左側のナビゲーション サイドバーを完全に削除するか、個々のメニュー エントリをトリミングします。履歴、プレイリスト、後で見る、気に入ったビデオ、ダウンロード、サブスクリプション、トレンド、音楽、ゲーム、ニュース、その他のセクションから表示し続けるものを選択します。コンテンツ内のナビゲーションを減らしたい場合は、フッター リンクをクリアします。

トップバーも簡素化し、通知、アップロードボタン、音声検索、仮想キーボードボタン、検索タグを非表示にします。これらは可視性の設定です。プレイリスト、サブスクリプション、アカウントのコンテンツは削除されません。

検索結果とチャンネルページをクリーンアップする

チャンネル結果カード、関連検索の提案、情報カード、またはチャンネル ビデオ シェルフを非表示にして、検索結果をスキャンしやすくします。より密度の高い結果ページが必要な場合は、これらのコントロールをコンパクト モードと組み合わせます。

チャンネル ページでは、バナーとチャンネル トレーラーを非表示にします。大きな装飾要素を減らし、注目のトレーラーからの中断を少なくして、見つけたビデオを閲覧します。

表示するビデオ説明セクションを選択します

説明全体を非表示にするか、個々のセクションを選択します。オプションには、AI の概要、トランスクリプト、言及された人物、関連ビデオ、チャンネル カード、「これがどのように作られたか」、およびチャプターまたはエピソードが含まれます。

学習のためにトランスクリプトと章を表示したままにしておくか、短い説明が必要な場合は削除します。これらのコントロールは、既存のページ セクションを非表示にします。要約を生成したり、トランスクリプトを書き直したり、作成者のコンテンツを変更したりすることはありません。

学習や仕事に集中できるYouTube

サイトの使用方法に焦点を当てた表示設定を構築します。

• 学生: 授業を見たり試験の準備をしたりする際に、フィードが乱雑になるのを減らします。
• 開発者と研究者: 深い作業中にチュートリアルとデモンストレーションを手の届くところに置いてください。
• 言語学習者: 静かなページと正確な速度調整を組み合わせます。
• 通常の閲覧者: 定期購読を閲覧しやすくし、繰り返しの提案を減らします。
• デジタル ミニマリスト: 視覚的なノイズを除去し、意図的な視聴をデジタル デトックス ルーチンの一部にします。

小規模なクリーンアップの場合は ライト を選択し、より広範なフィルターのセットの場合は バランス を選択します。どちらのプリセットも編集およびリセットできます。 カスタム はクリーンアップ スイッチがオフの状態で開始され、独自の構成を構築できるようになります。インストール時にデフォルトで バランス プリセットが選択されます。

ニーズの変化に応じて個々の設定を切り替えるか、拡張機能のキーボード ショートカットを使用して構成全体のオンとオフを切り替えます。強制的なフォーカスタイマー、使用量の割り当て、またはロックされた勉強セッションはありません。

無料・オープンソース、設定はブラウザ内に保存

すべての拡張機能設定は、支払いや登録なしで利用できます。サブスクリプション、トライアルのカウントダウン、分析、個人データの収集はありません。設定はブラウザにローカルに保存されます。完全なソース コードは、MIT ライセンスに基づいて GitHub で入手できます。

Chrome のデスクトップ Web サイト向けに設計されており、52 言語で利用できるインターフェースを備えています。モバイルアプリは変更されません。インターフェイスのクリーンアップのほとんどは CSS を使用します。再生およびその他のインタラクティブ機能はローカル JavaScript を使用します。

3 つのステップで始めましょう

1. YouTube Clean を Chrome に追加し、Web サイトを開きます。
2. 拡張機能アイコンをクリックしてサイドパネルを開きます。
3. プリセットを選択し、必要なフィード、ナビゲーション、および再生設定を調整します。

インターフェイスの表示設定の変更は、切り替えると適用されます。拡張機能をツールバーに固定して、コントロールにアクセスしやすいようにします。ページ要素が変更され、フィルターがそれに一致しなくなった場合は、問題を報告して確認できるようにしてください。
