YouTube Clean מסתיר Shorts, המלצות, תגובות ופרסומות — כך שבעמוד נשאר רק הסרטון שבאתם לראות.

יוטיוב בנוי כדי שתמשיכו לגלול: מדף ה‑Shorts שאין לו סוף, קיר ההמלצות לצד הנגן, התצוגות המקדימות שמתחילות מכל תזוזה של העכבר, התמונות הממוזערות שהופכות «סרטון אחד» לשעה. YouTube Clean מחזיר לכם את המקום הזה. פותחים את הפאנל הצדדי, מזיזים מתג, והעודף נעלם מיד: בלי לרענן את הדף, בלי חשבון, בלי הגדרות.

יותר מ‑60 מתגים, פאנל צדדי אחד, תוצאה מיידית. חינם, קוד פתוח, בלי מעקב.

מה אפשר לנקות

פיד והמלצות. הסתירו מדפי Shorts בכל מקום שבו הם מופיעים, מיקסים ופלייליסטים, את הבלוקים «חקירה» ו«חדשות» וסרטונים לחברי ערוץ בלבד. כבו תצוגה מקדימה אוטומטית במעבר עכבר, הפעילו מצב קומפקטי כדי שייכנסו יותר סרטונים למסך, והסתירו סרטונים שכבר צפיתם בהם — בנפרד בדף הבית, במינויים, בדפי ערוץ ובהמלצות.

עמוד הסרטון. הסתירו תגובות, סרטונים מומלצים לצד הנגן, לייק/דיסלייק, כפתורי פעולה, את התיאור, צ'אט חי, מרצ'נדייז וכרטיסים, כרטיסיות מסך סיום ותמונות ערוץ. את התיאור אפשר לפרק עוד: מקטע ה‑AI (Gemini), תמלול, אנשים שהוזכרו, סרטונים קשורים, כרטיס הערוץ, «איך זה נוצר», פרקים ואפיזודות.

פרסומות וקידומים. הסתירו באנרים של יוטיוב, סרטונים ממומנים בפיד ולוחות מידע פרסומיים, והפעילו דילוג אוטומטי ניסיוני כדי שפרסומות שניתן לדלג עליהן יטופלו לבד.

נגן והפעלה. הוסיפו סרגל מהירות ישירות לפקדי הנגן, העדיפו קצב סיביות משופר עם Premium, אכפו את הקודק H.264 (בחסימת VP9 ו‑AV1) כדי שכרטיס המסך יפענח במקום שהמעבד יתחמם, הגבילו ל‑30 fps במחשבים חלשים, והסתירו את כפתורי הנגן הקטן, מצב הקולנוע, הכתוביות וההפעלה האוטומטית.

Shorts. אם אתם משאירים Shorts, שיהיה בתנאים שלכם: בקרת מהירות ייעודית ומעבר אוטומטי לסרטון הבא.

סרגל צד וניווט. הסתירו את סרגל הצד לגמרי, או גזמו אותו פריט אחרי פריט — Shorts, הערוץ שלי, היסטוריה, פלייליסטים, הסרטונים שלכם, לצפייה מאוחרת, סרטונים שאהבתי, סרטים, הורדות, כל רשימת המינויים, פופולרי, מוזיקה, שידור חי, גיימינג, חדשות, ספורט, הקישורים ל‑YouTube Premium / Music / Kids / Studio והפוטר עם קישורי «אודות».

חיפוש וערוצים. הסתירו ערוצים בתוצאות החיפוש, חיפושים קשורים, כרטיס המידע ומדף הסרטונים של הערוץ. בדפי ערוץ אפשר להסיר את הבאנר ואת הטריילר שמתנגן מעצמו.

סרגל עליון. הסתירו את כפתורי החיפוש הקולי והמקלדת הווירטואלית, תגיות חיפוש, כפתור ההעלאה והתראות.

ערכות מוכנות למי שלא רוצה לכוונן כלום

בחרו «קל» לניקוי עדין, «מאוזן» ליוטיוב יומיומי בלי הסחות, או «מקסימלי» כדי להוריד כמעט הכול. כל ערכה ניתנת לעריכה ולאיפוס לברירת המחדל, ו«מותאם אישית» נבנה מאפס. קיצור מקלדת מדליק ומכבה את כל התוסף כשצריך את יוטיוב המקורי לרגע.
