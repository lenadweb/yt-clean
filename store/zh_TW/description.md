YouTube Clean 會隱藏 Shorts、推薦影片、留言和廣告，讓頁面上只留下你真正想看的那支影片。

YouTube 天生就是要讓你一直滑下去：沒完沒了的 Shorts 陳列架、播放器旁那面推薦牆、游標一掃就自動播放的預覽、把「只看一支」變成一小時的縮圖。YouTube Clean 把這塊空間還給你。打開側邊面板、撥一個開關，多餘的東西立刻消失——不必重新整理頁面，不必帳號，不必設定。

60 多個開關，一個側邊面板，即時生效。免費、開放原始碼、不做追蹤。

可以清掉什麼

首頁與推薦。在任何出現的位置隱藏 Shorts 區塊，隱藏合輯與播放清單、「探索」和「新聞」區塊、會員專屬影片。關掉游標懸停自動預覽，開啟精簡模式讓一個畫面塞下更多影片，並隱藏看過的影片——首頁、訂閱內容、頻道頁與推薦可分別設定。

影片頁。隱藏留言、播放器旁的推薦影片、喜歡/不喜歡、動作按鈕、說明欄、即時聊天、商品與門票、結束畫面資訊卡和頻道圖片。說明欄還能再拆細：AI 區塊（Gemini）、逐字稿、提到的人物、相關影片、頻道資訊卡、「製作方式」、章節與集數。

廣告與推廣。隱藏 YouTube 橫幅、動態消息中的贊助影片和廣告資訊面板，再開啟實驗性的自動略過，可略過的廣告就會自己解決。

播放器與播放。把速度滑桿直接加進播放器控制列；有 Premium 時優先使用加強位元率；強制 H.264 編解碼（封鎖 VP9 與 AV1），讓顯示卡硬體解碼，而不是讓 CPU 發燙；在較弱的機器上限制為 30 fps；隱藏迷你播放器、劇院模式、字幕與自動播放按鈕。

Shorts。如果你留著 Shorts，就照你的規則來：獨立的速度控制，以及自動切換到下一支 Short。

側邊欄與導覽。可以整條隱藏側邊欄，也可以一項一項修剪——Shorts、我的頻道、觀看紀錄、播放清單、你的影片、稍後觀看、喜歡的影片、電影、下載內容、整份訂閱清單、發燒影片、音樂、直播、遊戲、新聞、運動，以及 YouTube Premium / Music / Kids / Studio 連結和帶「關於」連結的頁尾。

搜尋與頻道。隱藏搜尋結果中的頻道、相關搜尋、搜尋資訊卡和頻道影片架。在頻道頁上拿掉橫幅和會自動播放的預告片。

頂端列。隱藏語音搜尋與虛擬鍵盤按鈕、搜尋標籤、上傳按鈕和通知。

給不想調設定的人準備的預設

想輕輕收拾就選「輕度」，想要日常無干擾的 YouTube 就選「平衡」，想幾乎全部清空就選「最大」。每個預設都能編輯、也能一鍵回到預設值，「自訂」則完全由你從零打造。快捷鍵可以一鍵開關整個擴充功能，臨時需要原版 YouTube 時很方便。

隱私，直說

不用帳號、不用登入、沒有分析統計、沒有追蹤、不收集資料。設定存在瀏覽器的本機儲存空間，從不外傳。完整原始碼以 MIT 授權公開在 GitHub，不必只聽我們說。

為速度而生

幾乎所有選項都在建置時編譯成純 CSS，瀏覽時零負擔。只有少數需要行為邏輯的功能會執行 JavaScript。Manifest V3，沒有遠端程式碼，沒有背景負載。

如何開始

安裝擴充功能，點一下圖示在 YouTube 旁開啟側邊面板，然後選一個預設或逐一撥動開關。變更會立刻套用到目前的頁面。

支援 Chrome、Opera、Edge、Brave 及其他以 Chromium 為基礎的瀏覽器。

常見問題

這是廣告封鎖器嗎？不完全是。它會隱藏橫幅、動態消息中的贊助資訊卡和廣告資訊面板，也能自動略過可略過的廣告（實驗性）。與專門的廣告封鎖器一起使用不會衝突。

會不會把 YouTube 弄壞？所有功能都要你主動開啟，而且可逆——關掉開關，元素立刻回來。

需要帳號嗎？不需要。裝上就能用。

真的免費嗎？是的：免費且開放原始碼，沒有付費版，也沒有推銷。

有什麼沒有照你想要的方式隱藏？到 GitHub 開個 issue——功能清單就是靠使用者需求長出來的。
