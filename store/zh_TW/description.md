遮蔽 YouTube Shorts，整理推薦內容，減少觀看時的干擾。YouTube Clean 將資訊流過濾、隱藏評論、實驗性廣告跳過和播放控制整合到一個免費的 Chrome 擴充套件中。保留想看的影片，移除周圍多餘的內容，讓頁面更符合你的使用習慣。

在影片旁的側邊面板中使用 70 多項設定。可以選擇預設，也可以分別調整首頁、訂閱、搜尋結果、觀看頁面、播放器和左側導航。免費、開源，無需註冊或付費訂閱，不進行跟蹤。

主要功能一覽

• 隱藏短影片版塊及對應的導航入口。
• 過濾已觀看影片、合輯、播放列表和會員專享內容。
• 隱藏評論、直播聊天、片尾卡片和推廣面板。
• 使用緊湊佈局，縮小首頁和搜尋結果中的影片縮圖。
• 透過播放器內的滑塊，將速度調整為 0.25 倍至 3 倍。
• 使用鍵盤快捷鍵開啟或關閉整套清理設定。

遮蔽 Shorts，減少無休止的滾動

想隱藏短影片，同時繼續觀看普通影片？可以隱藏資訊流中的短影片版塊、搜尋結果中的相關條目，以及左側選單中的入口。配合使用資訊流和導航設定，可以減少進入短影片連續滾動的常見途徑。

使用現成預設，或單獨開啟所需選項。移除分散注意力的短影片內容時，長影片、訂閱和搜尋仍然可用。這些設定改變介面中的顯示內容，並不會阻止透過直接連結開啟影片。

從資訊流中隱藏已觀看影片

不想反覆看到已經看過的內容？可以分別在首頁、訂閱、頻道頁面和觀看頁面的推薦列表中隱藏已觀看影片。例如，只清理訂閱列表，保留頻道頁面中想重溫的影片；也可以同時啟用全部四項設定。

擴充套件根據影片縮圖上的觀看進度條判斷內容是否符合過濾條件。它只過濾頁面顯示，不會刪除觀看記錄，也不會把影片標記為已觀看。沒有匹配進度條的影片可能仍然顯示。

整理推薦、合輯和播放列表

透過過濾特定型別的內容，為有用的推薦留出空間。可以隱藏合輯、播放列表、會員專享影片，以及探索或新聞版塊。結合已觀看影片過濾功能，減少重複推薦和資訊流中的雜亂內容。

你可以決定保留什麼，同時繼續發現新影片。擴充套件過濾選定的內容型別，不會替換推薦演算法，也不會清空整個首頁資訊流。

隱藏評論、直播聊天和片尾卡片

觀看課程時，不必讓下方的討論分散注意力。可以隱藏影片評論和直播聊天，移除播放器上的片尾卡片及卡片提示。

還可以隱藏商品與票務版塊、贊與踩、操作按鈕和頻道頭像。每項設定都相互獨立，因此可以保留簡介、字幕按鈕等常用元素，同時簡化觀看頁面。

跳過廣告，隱藏推廣影片

隱藏橫幅廣告、推廣影片卡片和廣告資訊面板，減少頁面上的廣告內容。各項設定獨立執行，你可以選擇搜尋和觀看頁面中需要隱藏的推廣元素。

可選的自動跳過功能會嘗試跳過影片廣告。該功能處於實驗階段，效果取決於當前播放器和廣告格式，需要單獨開啟。它不是網路層廣告攔截器，不能保證完全無廣告。

關閉滑鼠懸停時的自動預覽

不再讓滑鼠經過影片時自動開始播放預覽。關閉懸停預覽後，可以在更安靜、靜態的資訊流中瀏覽標題，減少動態畫面的干擾。

此設定控制縮圖預覽。另一個隱藏自動播放開關的選項只會移除播放器中的按鈕，不會關閉下一個影片的自動播放。

更小的縮圖與緊湊佈局

想在一屏內看到更多影片，而不是過大的封面？緊湊模式可以調整首頁、搜尋結果和觀看頁面推薦列表的佈局。較小的縮圖、較窄的間距和更密集的排列，讓瀏覽標題和比較結果更方便。

用緊湊網格查詢教程、尋找下一集或瀏覽搜尋結果，減少滾動操作。這是一套現成佈局，無需編輯 CSS，也無需手動設定每一列的寬度。

影片速度控制：慢放或加速至 3 倍

直接在播放器內調整速度。滑塊範圍為 0.25 倍至 3 倍，可以按 0.05 倍的步長微調，也可以選擇 1.25 倍、1.5 倍、2 倍或 3 倍等預設。所選速度會儲存在擴充套件設定中。

學習語言時放慢語速，按自己的節奏理解操作演示，或加速觀看熟悉的課程。速度控制適用於普通觀看頁面中的影片。也可以隱藏迷你播放器、影院模式或字幕按鈕，讓控制區域更簡潔。

H.264、60 fps 與增強位元率設定

高階播放選項可以透過遮蔽 VP9 和 AV1 來強制使用 H.264，也可以遮蔽 60 fps 影片流，改用較低幀率。這可能適合老舊膝上型電腦或解碼支援有限的裝置。硬體解碼、CPU 佔用和可用畫質取決於裝置及影片提供的流；強制 H.264 可能限制可選解析度。

Premium 訂閱使用者可以在選項可用時優先使用增強位元率。這只是選擇已有的播放畫質，不會解鎖付費功能。另一個實驗性選項可以調整播放器使用的頻寬估計值，但不會改變實際網速。

隱藏側邊欄，簡化導航

可以隱藏整個左側導航選單，也可以只移除部分條目。自行決定是否顯示歷史記錄、播放列表、稍後觀看、喜歡的影片、下載、訂閱、熱門、音樂、遊戲、新聞等入口，也可以隱藏選單底部的連結。

頂部欄也能精簡：隱藏通知、上傳按鈕、語音搜尋、虛擬鍵盤按鈕或搜尋標籤。這些選項只改變顯示狀態，不會刪除播放列表、訂閱或賬號內容。

清理搜尋結果和頻道頁面

隱藏搜尋結果中的頻道卡片、相關搜尋建議、資訊卡片和頻道影片版塊，讓結果更容易瀏覽。與緊湊模式搭配使用，可以在螢幕上容納更多內容。

在頻道頁面中隱藏橫幅和頻道預告片，減少大型裝飾元素及預告影片帶來的干擾，直接尋找想看的內容。

只保留需要的影片簡介部分

隱藏整個簡介，或單獨選擇各個部分，包括 AI 摘要、文字稿、提及的人物、相關影片、頻道卡片、製作方式說明，以及章節或集數。

學習時保留文字稿和章節，或將其隱藏以縮短簡介。這些設定只隱藏現有頁面元素，不會生成摘要、改寫文字稿或更改創作者的內容。

用於學習和專注工作的無干擾 YouTube

根據使用場景搭配設定：

• 學生：觀看課程或備考時，減少資訊流中的雜亂內容。
• 開發者和研究人員：專注工作時，仍能方便地檢視教程和演示。
• 語言學習者：結合簡潔頁面與精細的速度調整。
• 日常觀眾：更方便地瀏覽訂閱，減少重複推薦。
• 數字極簡主義者：減少視覺噪音，把有意識的觀看融入數字減負習慣。

選擇“輕度”進行基本清理，或選擇“平衡”啟用更多過濾選項。兩種預設都可以編輯和重置。“自訂”的清理開關初始為關閉狀態，方便從頭配置。安裝後預設使用“平衡”預設。

根據需要調整單個設定，或使用鍵盤快捷鍵開啟和關閉整套配置。沒有強制專注計時器、使用額度或鎖定的學習時段。

免費、開源，不收集個人資料

所有擴充套件設定無需付費或註冊即可使用。沒有付費訂閱、試用倒計時、使用分析或個人資料收集。偏好設定儲存在本地瀏覽器中，完整原始碼以 MIT 許可證在 GitHub 上公開。

適用於 Chrome 中的桌面版網站，介面支援 52 種語言，不修改移動應用。大部分介面清理透過 CSS 實現；播放和其他互動功能使用本地 JavaScript。

三個步驟開始使用

1. 在 Chrome 中安裝 YouTube Clean 並開啟網站。
2. 點選擴充套件圖示，開啟側邊面板。
3. 選擇預設，再調整資訊流、導航和播放選項。

切換設定時，介面元素的顯示狀態會隨之變化。可以將擴充套件固定到工具欄，方便隨時開啟。如果網站更新後某個過濾器失效，請反饋問題以便檢查。
